# V0.5.0-alpha.3.2.1 部署与更新

当前交付：**V0.5.0-alpha.3.2.1**。IndexedDB **V15** / Backup **V10** 不变。

## 更新

把 ZIP 解压为：

```text
D:\ai\ai-companion-phone-v0.5.0-alpha.3.2.1
```

覆盖到 Git 工作区：

```powershell
cd "D:\ai"

robocopy `
  ".\ai-companion-phone-v0.5.0-alpha.3.2.1" `
  ".\ai-companion-phone-git-clean" `
  /E `
  /XD .git node_modules dist `
  /XF "*.tsbuildinfo" `
  /R:2 `
  /W:1
```

确认 `失败 0` 后：

```powershell
cd "D:\ai\ai-companion-phone-git-clean"
Select-String '"version"' package.json
```

应为：

```text
"version": "0.5.0-alpha.3.2.1"
```
