## 7. alpha.3 专项人工回归

### A. 从用户消息重新回复 / rewind

找一条后面已经有多轮剧情的**用户消息**：

```text
长按 → 从这条消息重新回复
```

先点取消：剧情必须完全不变。

再重新操作并确认：

- 锚点用户消息保留；
- 锚点之后旧消息被截断；
- 生成新的回复；
- 旧后续剧情不应通过 Memory / 当前地点 / Presence / Thought 明显“穿越回来”；
- 手工/导入记忆不应因为普通 rewind 被误删。

### B. Branch

在一条较早消息上：

```text
长按 → 从这里创建聊天分支
```

确认：

- 进入新的 conversation URL；
- 只复制到选中节点为止；
- 父聊天保持不变；
- 新分支继续聊天不会改变父聊天；
- 在父聊天分支点之后才发生的地点/关系/剧情记忆，不应直接出现在新分支。

### C. Greeting reset

当前聊天已经有剧情时切换另一条角色卡开场：

- 应出现确认；
- 取消后剧情完全不变；
- 确认后只剩新 greeting seed；
- 旧聊天、旧会话记忆、StateHistory、Prompt Debug 被清理；
- Character Card / Persona / WorldBook / Regex 不删除。

### D. Free opening

从已有剧情切换“自由开局”：

- 确认后消息清空；
- 本会话记忆清空；
- Prompt Debug 也应清空；
- 下一条用户消息重新建立当前场景。

### E. 基础回归

再任选一个真实社区角色测试：

- WorldBook；
- Regex / Community UI；
- scene-merged 动作+台词；
- 显式 multiBubble；
- 删除单条消息；
- 快速 A→B→A→B 切换聊天。
