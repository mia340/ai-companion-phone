## 人工验收

1. 首页点击「编辑」，修改聊天 / 朋友圈 / 设置等 App 图标，刷新页面后图标仍存在。
2. 上传一张大图，确认图标会被裁切、压缩，不会把原图直接塞进 IndexedDB。
3. 同一角色创建两个聊天：聊天 A 产生事实记忆，聊天 B 应能命中；聊天 A 的 `story` 剧情记忆不应自动出现在聊天 B。
4. 在「记忆管理」中把一条剧情记忆切换为「跨聊天共享」，再切到另一个聊天，应能命中；移出共享后应重新隔离。
5. branch / rewind / 自由开局 / 删除聊天后，角色共享记忆仍然存在。
6. 朋友圈由角色发布动态时，可以自然参考共享记忆，但不应直接复述整条记忆列表。
