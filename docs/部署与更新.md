# 部署与更新

> 当前示例版本：**V0.4.5.0**。

## 1. 解压

```text
D:\ai\ai-companion-phone-v0.4.5.0
```

确认直接包含 `package.json / src / docs / scripts / public`，不要套娃目录。

## 2. 覆盖 Git 工作目录

```powershell
cd "D:\ai"

robocopy `
  ".\ai-companion-phone-v0.4.5.0" `
  ".\ai-companion-phone-git-clean" `
  /E `
  /XD .git node_modules dist `
  /XF "*.tsbuildinfo" `
  /R:2 `
  /W:1
```

必须确认：

```text
失败        0
```

## 3. 检查版本

```powershell
cd "D:\ai\ai-companion-phone-git-clean"
Select-String '"version"' package.json
```

应看到：

```text
"version": "0.4.5.0"
```

## 4. Build

首次没有依赖时先：

```powershell
npm install
```

然后：

```powershell
npm run build
```

成功应经过 `vue-tsc -b`、`vite build`、PWA generateSW，并生成 `dist/sw.js`。

出现 `error TSxxxx` 时不要 commit / push。

## 5. 开发运行

```powershell
npm run dev
```

手机局域网：

```powershell
npm run dev -- --host 0.0.0.0
```

## 6. Git

Build 与测试通过后：

```powershell
git status
git add .
git status
git commit -m "feat: WorldBook Engine V2 phase 1 v0.4.5.0"
git push origin main
```

若 `git push` 因 `github.com:443` 失败但 commit 已成功，不要重复 commit；网络恢复后只重试 `git push origin main`。

## 7. V0.4.5.0 专项测试

Build 通过后至少测试：

1. 普通关键词条：无关键词不触发，有关键词触发；
2. selectiveLogic：AND ANY / NOT ALL / NOT ANY / AND ALL；
3. recursion：A 内容包含 B 的关键词，只发 A 的关键词时 B 可递归触发；
4. excludeRecursion / preventRecursion / delayUntilRecursion；
5. sticky=2 / cooldown=2 / delay=2 的消息生命周期；
6. 同 group 两条只激活一条，useGroupScoring 时更多 key 命中的条目胜出；
7. 设置较小 tokenBudget，Prompt Debug 应出现“预算淘汰”，删除预算后恢复；
8. position=4 + depth/role，在 Prompt Debug 的“最近聊天上下文”中看到 @D 注入；
9. Outlet：Preset 中写 `{{outlet::测试}}` 能得到 position=7 且 outletName=测试 的内容；
10. 原有大型按需资源、Mandatory UI、Regex/HTML 不被 WorldBook V2 破坏。

IndexedDB V14 / Backup V9 不变。
