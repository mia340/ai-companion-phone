# 部署与更新

> 当前示例版本：**V0.4.4.7.2**。

## 1. 解压

```text
D:\ai\ai-companion-phone-v0.4.4.7.2
```

确认直接包含 `package.json / src / docs / scripts / public`，不要套娃目录。

## 2. 覆盖 Git 工作目录

```powershell
cd "D:\ai"

robocopy `
  ".\ai-companion-phone-v0.4.4.7.2" `
  ".\ai-companion-phone-git-clean" `
  /E `
  /XD .git node_modules dist `
  /XF "*.tsbuildinfo" `
  /R:2 `
  /W:1
```

必须确认：

```text
失败        0
```

## 3. 检查版本

```powershell
cd "D:\ai\ai-companion-phone-git-clean"
Select-String '"version"' package.json
```

应看到：

```text
"version": "0.4.4.7.2"
```

## 4. Build

首次没有依赖时先：

```powershell
npm install
```

然后：

```powershell
npm run build
```

成功应经过 `vue-tsc -b`、`vite build`、PWA generateSW，并生成 `dist/sw.js`。

出现 `error TSxxxx` 时不要 commit / push。

## 5. 开发运行

```powershell
npm run dev
```

手机局域网：

```powershell
npm run dev -- --host 0.0.0.0
```

## 6. Git

Build 与测试通过后：

```powershell
git status
git add .
git status
git commit -m "docs: consolidate project documentation v0.4.4.7.2"
git push origin main
```

若 `git push` 因 `github.com:443` 失败但 commit 已成功，不要重复 commit；网络恢复后只重试 `git push origin main`。

## 7. docs-only 版本测试

V0.4.4.7.2 不改运行代码：

1. `npm run build` 仍需通过；
2. 确认 docs 只有预期 10 份；
3. 不需要重跑完整角色卡功能矩阵；
4. IndexedDB V14 / Backup V9 不变。
