# 部署与更新

> 当前示例版本：**V0.4.7.1**。

## 1. 解压

```text
D:\ai\ai-companion-phone-v0.4.7.1
```

确认直接包含 `package.json / src / docs / scripts / public`，不要套娃目录。

## 2. 覆盖 Git 工作目录

```powershell
cd "D:\ai"

robocopy `
  ".\ai-companion-phone-v0.4.7.1" `
  ".\ai-companion-phone-git-clean" `
  /E `
  /XD .git node_modules dist `
  /XF "*.tsbuildinfo" `
  /R:2 `
  /W:1
```

必须确认：

```text
失败        0
```

## 3. 检查版本

```powershell
cd "D:\ai\ai-companion-phone-git-clean"
Select-String '"version"' package.json
```

应看到：

```text
"version": "0.4.7.1"
```

## 4. Build

首次没有依赖时先：

```powershell
npm install
```

然后：

```powershell
npm run build
```

成功应经过 `vue-tsc -b`、`vite build`、PWA generateSW，并生成 `dist/sw.js`。

出现 `error TSxxxx` 时不要 commit / push。

## 5. 开发运行

```powershell
npm run dev
```

手机局域网：

```powershell
npm run dev -- --host 0.0.0.0
```

## 6. Git

Build 与测试通过后：

```powershell
git status
git add .
git status
git commit -m "fix: stabilize community UI and edited-message regeneration v0.4.7.1"
git push origin main
```

若 `git push` 因 `github.com:443` 失败但 commit 已成功，不要重复 commit；网络恢复后只重试 `git push origin main`。

## 7. V0.4.7.1 用户验收测试

协议级 Regex / WorldBook 组合由开发回归负责。普通使用只建议做 4 组真实验收：

1. **作者 UI**：带旧 Rich 开场的卡，新聊天开场不应再直接透明漂浮；若开场内含 Markdown 图片，应显示为图片。带 WorldBook HTML 状态栏的卡继续聊天，`【状态栏】 + 【正文】` 应恢复为作者模板，不再只显示白色纯文字状态栏。
2. **纯手机 / 动作分离**：纯手机可一条或多条角色消息，多条必须共同回应最新用户消息；动作/台词分开在自然反应存在时应出现独立动作，远程动作不改变 Presence。
3. **编辑后重新回复**：编辑用户消息后确认重生成，旧后续被移除，角色按编辑后的消息重新回复；手工/导入记忆、角色卡、Persona、资源绑定不删除。
4. **旧功能回归**：默认/备用/自由开场、论坛/微信 Resource Session、场景合并、资源库宽度、多聊天快速检查。

通过后再提交 Git。
