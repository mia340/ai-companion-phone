# Companion Avatar / 穿搭 V1.3

版本：`0.5.0-alpha.5.9.3`

## 目标

V1.3 把上一版仍偏“程序化方块人”的表现重做成更接近暖系农场 RPG / 像素换装游戏的公共 Avatar Runtime。重点不是照搬任何第三方素材，而是吸收成熟像素游戏在角色比例、五官可读性、发型轮廓、套装完整度与换装工作台上的设计方法。

## 64×80 新像素骨架

- `CompanionPixelAvatar` 从 48×64 重构到 64×80。
- 脸部重新分配额头、眼睛、嘴和腮红位置，减少“方脸 / 青蛙脸”感。
- 男女都使用更窄、更自然的肩宽、手臂与腿部比例。
- 长发 / 卷发 / 半扎 / 马尾 / 编发继续前后分层，不遮完整张脸。
- 男版新增蓬松层次发型；女版新增半扎长发。
- 新增三种眼睛：温柔圆眼、清亮大眼、安静垂眼。

## 更多服装版型

女版新增泡泡袖衬衫、学院领衬衫、蕾丝开衫、短款外套、格纹学院裙、牛仔短裙、居家软裤等。

男版新增休闲衬衫外套、软针织开衫、户外工装外套、学院马甲、休闲卡其裤、背带短裤、格纹居家裤等。

鞋履新增复古牛津鞋、户外皮靴、厚底短靴、软萌毛绒拖鞋。

## 配饰分层 V2

在原有头饰 / 脸部 / 颈部基础上新增：

- 头饰：大蝴蝶结、花朵发饰、报童帽、针织帽等。
- 脸部：小耳饰、耳机。
- 颈部：领巾、学院丝带。
- 随身物：斜挎包、小手袋、双肩包、相机、书本、花束、马克杯。
- 腿部：短袜、长袜、花边袜、连裤袜。

这些层可以同时存在，不再互相抢占一个 accessory 槽。

## 纹理与强调色

每套衣服新增：

- `pattern`：纯色 / 细条纹 / 格纹 / 碎花 / 圆点。
- `accentColor`：领口、丝带、纹理、配饰和细节的第二颜色。

强调色支持和主色一样的预设颜色、原生取色器与 HEX 自定义颜色。

## 套装衣橱预览

“套装”页不再只有文字按钮。每套 Outfit 会实时用 `CompanionPixelAvatar` 生成小预览，方便直接比较不同风格。

## 每日自主换装

保留 V1.2 的每日换装模式，但自动日常轮换现在默认排除 `sleepwear` 和 `private`，避免角色白天随机穿睡衣或私房套装。睡衣 / 私房仍可由用户手动选择。

## 数据兼容

- IndexedDB：V18，不升级。
- Backup：V12，不升级。
- HomeLayout revision：14，不升级。
- Wardrobe state：仍为 V1 非索引字段。
- `carrywear`、`legwear`、`pattern`、`accentColor` 都是可选兼容字段。
- V1 / V1.1 / V1.2 存档加载时自动补默认值与新风格套装。
