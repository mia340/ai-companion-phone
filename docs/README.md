# V0.4.4.1 · AI 内容权威与 Token 硬停止

角色台词、动作、心理、情绪、关系感受、主动消息和剧情推进现在只允许来自真实 AI 与原角色卡资源。小手机负责上下文编排、协议解析与 UI 渲染，不再提供 Mock / 本地角色化兜底。Token、上下文窗口或 API 额度不足时，本轮直接停止并删除不完整回复。IndexedDB 当前为 V13，Backup 仍为 V9。

详见 `V0.4.4.1_AI内容权威与Token硬停止.md`。

自动模式现在对社区卡和原生角色都保持 AI / 原卡原样输出；只有用户明确选择“小手机增强”才允许额外消息整形。Token/上下文/额度不足时本轮硬停止，不用本地内容续写。

# V0.4.4.0 · 通用角色卡兼容内核

当前版本把角色卡兼容从“针对某张卡修补”改为结构化兼容层：社区角色默认原卡优先，原卡有 UI/Regex/世界书就按原资源运行，没有就保持普通文本；小手机自己的互动协议、关系积分、设备叙事等仅作为可选增强，不再覆盖导入角色卡。IndexedDB 当前为 V12，Backup 格式仍为 V9。

详见 `V0.4.4.0_通用角色卡兼容内核与数据库清洗.md`。

## 流式回复说明

默认会开启：

```text
聊天页 → 右上角 ••• → 聊天 → 边想边回复
```

接口支持标准 OpenAI SSE 时会实时显示；接口忽略 `stream: true` 但返回普通 JSON 时，应用仍能正常显示完整回复。若某个兼容接口的流式实现异常，可在聊天设置中关闭“边想边回复”。

## 图片理解使用条件

图片回复取决于具体模型是否支持视觉输入，同时要求接口兼容 OpenAI 多模态 `image_url` 消息格式。可进入：

```text
设置 → API 与模型 → 图片理解
```

保存接口配置后点击“测试图片理解”。

## 隐私与数据

- 图片理解会把图片发送给当前配置的模型服务
- 请避免上传身份证、银行卡和私密文件等敏感内容
- 聊天数据保存在当前浏览器的 IndexedDB 中，不会自动跨设备同步
- 导出备份时可以关闭“包含聊天图片”，减小文件体积
