# Companion Avatar / 穿搭 V1.2

版本：`0.5.0-alpha.5.9.2`

## 目标

V1.2 继续把穿搭从“设置面板”推进成可复用的像素角色系统：角色预览始终可见，人物比例重画，服装与配饰数量扩充，颜色支持自由 HEX / 原生取色器，并加入角色每日自主换装。

## 像素角色重构

- 公共 `CompanionPixelAvatar` 从 64×82 的宽块骨架改成更紧凑的 48×64 暖系 RPG 像素比例。
- 头发继续分为前发 / 后发 / 侧边结构，脸部保持可见。
- 衣服、裙装、裤装、鞋履和帽饰有独立轮廓，不只是换颜色。
- 仍为原创程序化 SVG，不包含第三方游戏素材。

## 衣服与配饰

男女版型都扩充了上装与下装；配饰从单一槽位扩成：

- 头饰：蝴蝶结、发带、小花、贝雷帽、棒球帽、草帽、小巫师帽等。
- 脸部：圆框 / 方框眼镜、发夹等。
- 颈部：项链、颈链、围巾、领结等。
- 鞋履：运动鞋、乐福鞋、短靴、玛丽珍、居家拖鞋。

旧 V1 / V1.1 的 `accessory` 字段继续兼容迁移。

## 自由配色

每个主要颜色槽位保留快速预设，并增加：

- 原生颜色选择器。
- HEX 颜色输入。
- “应用并收藏”的常用颜色列表。
- 自定义颜色直接进入 Avatar Runtime，不会被强制映射回固定色板。

## 每日自主换装

每个角色都可以选择：

- `TA 自己决定`：每天从自己的衣橱稳定选择一套；同一天保持一致，并尽量避开最近两套。
- `先问我`：保留自动换装意图，但不自动切换。
- `只由我换`：完全手动。

用户自己的 Avatar 默认仍为手动。每日选择保留最近 30 天 Outfit History，不把每天穿什么写进长期 Memory。

## 跨 App 复用

`loadWardrobeState()` 会在角色使用 Avatar Runtime 时解析当天造型，所以飞行棋和后续小游戏可以共享同一天的角色穿搭。

## 数据兼容

- IndexedDB：V18，不升级。
- Backup：V12，不升级。
- Wardrobe state：仍为 V1 非索引字段，新增字段均为可选兼容字段。
- 老存档会自动补充基础推荐套装与新的配饰槽位。
