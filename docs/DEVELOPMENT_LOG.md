## 2026-08-17 · V0.4.4.7 多会话、场景状态机与白蓝主题

- Character 与 Conversation 生命周期解耦；同一角色卡可拥有多份独立聊天，不再通过重复导入角色来“重开剧情”。
- 新聊天统一提供自由开局 / 作者开场选择；自由开局不把 first_mes 当作当前历史，scenario 只保留作者背景语义，用户本会话事实可覆盖当前场景。
- 再次导入完全相同 Raw Card 时本地检测已有角色，并提供“用已有角色新建聊天”；仍保留用户主动另存为新角色的自由。
- Branch V2 从指定消息节点复制消息、设置、可追溯记忆和状态历史，并按节点前历史重建 ConversationState，避免把后续剧情状态穿越回旧分支。
- Presence 从“手动永久锁”改为当前场景状态机；用户明确离开/回家/上车/来到身边等动作在请求 AI 前更新 together/remote，弱意图不会提前改变。
- Action Parser V2 / Dialogue Parser V2 区分状态栏括号、说话动作、备忘录/文件引用和真正发送语句。
- Author Text Status Header 支持 `: ： ∶ ﹕ ︰`；解决部分社区卡使用特殊 Unicode 冒号导致固定字段无法识别。
- Community UI Compiler V2 第一阶段对可识别固定 HTML 外壳使用“AI 动态数据 + 本地模板填充”，减少纯格式失败导致的第二次模型调用。
- 小手机应用自身主题由粉色改为白 + 极淡蓝；社区作者提供的 HTML/CSS 不改色。
- 数据库保持 IndexedDB V14 / Backup V9。

## 2026-08-14 · V0.4.4.4 Token 与角色卡架构瘦身

- 将社区角色卡运行链分为 Raw Card、Local Index、Prompt Compiler：本地拆卡只用于可读展示、索引和资源路由，默认不会消耗 API Token。
- 新增原卡阅读器，直接浏览作者原始角色字段、User 相关引用与世界书人物/人设条目，不再要求用户阅读 JSON。
- 社区 card-first Prompt 删除本地拆分字段的重复注入；角色卡内嵌 User Persona 也只发送作者原模板一次。
- 新增 Resource Intent Router，从资源名、关键词和作者触发说明本地识别本轮功能意图；例如用户自然请求某资源时提升为 Focus，而不是要求技术口令。
- 只有“大型 + 作者明确按需触发”的功能型 WorldBook 才可休眠；每轮必须输出的作者状态栏合同继续常驻，避免 Token 优化破坏社区卡。
- Prompt Debug 新增资源调度与预计节省字符；Provider 返回 usage 时同步记录真实输入/输出/总 Token，便于直接对比优化效果。
- 社区角色编辑页默认折叠小手机本地补充字段，避免把空字段误解为原卡缺失。
- 数据库保持 IndexedDB V14 / Backup V9。
