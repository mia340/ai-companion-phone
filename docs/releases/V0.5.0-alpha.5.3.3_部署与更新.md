# V0.5.0-alpha.5.3.3 部署与更新

本版本是 **5.3.2 时光 V1.2 的测试门禁热修**。5.3.2 失败点不是功能错误，而是测试仍匹配旧的单数文案“证据里”，而 Runtime 已升级为事件级多证据文案“这些证据里”。

## 修复内容

- 不修改生产 Runtime 行为。
- 主动旧事测试改为验证真正的安全语义：必须包含“不要补写”和“没有发生过的情节”。
- `event id` 与完整 `evidence ids` 的校验继续保留。
- IndexedDB V18 / Backup V12 / HomeLayout revision 12 均不变，不需要清数据。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  57 passed (57)
Tests       481 passed (481)
```

随后 `vue-tsc -b && vite build` 与 Release Safety 必须全部成功。
