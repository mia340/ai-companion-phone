# V0.5.0-alpha.5.1.7 部署与更新

本版本从 alpha.5.1.6 更新。按固定门禁：**解压新版本 → 验证 → 复制到 Git 仓库 → 再验证 → 推送部署**。

不要删除旧站点，不要清除浏览器站点数据、IndexedDB 或 LocalStorage。
> R3 是同一 alpha.5.1.7 的部署修正版：修复 Windows R2 首次 `vue-tsc` 暴露的桌面布局存储类型收窄错误。R2 不要继续部署。


## 1. 解压并验证新版本

将：

```text
ai-companion-phone-v0.5.0-alpha.5.1.7-windows-safe-r3.zip
```

放到 `D:\ai`。

PowerShell：

```powershell
cd D:\ai

$zip = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.7-windows-safe-r3.zip"
$new = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.7"

Test-Path $zip

if (Test-Path $new) {
    Remove-Item $new -Recurse -Force
}

Expand-Archive -Path $zip -DestinationPath $new -Force

Test-Path "$new\package.json"
Test-Path "$new\package-lock.json"

cd $new
npm ci
npm run verify
```

只有测试和构建都成功才继续。

## 2. 检查并更新 Git 仓库

```powershell
$repo = "D:\ai\ai-companion-phone-git-clean"
cd $repo
git status
```

必须先确认没有未提交的个人修改。

复制：

```powershell
$new  = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.7"
$repo = "D:\ai\ai-companion-phone-git-clean"

robocopy $new $repo /MIR /XD ".git" "node_modules" "dist"
```

再次验证：

```powershell
cd D:\ai\ai-companion-phone-git-clean
npm ci
npm run verify
```

## 3. 提交并推送

```powershell
git add -A
git status
git commit -m "release: v0.5.0-alpha.5.1.7"
git push origin main
```

如果 `git push` 只是网络报 `github.com:443` 无法连接，不要重新复制/重新 commit；网络恢复后只需再次执行 `git push origin main`。

## 4. GitHub Pages 确认

1. 打开 GitHub Actions，等待最新 workflow 绿色成功；
2. 再打开 GitHub Pages；
3. 如仍显示旧版，关闭旧标签页后重新打开或普通刷新一次；
4. 不要使用“清除站点数据”强制刷新。
