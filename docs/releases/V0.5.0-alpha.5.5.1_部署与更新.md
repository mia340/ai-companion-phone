# V0.5.0-alpha.5.5.1 部署与更新

本版本是心跳飞行棋 V1 的 Launcher 测试热修。5.5.0 的游戏 Runtime 测试已经通过，失败集中在旧 Launcher 测试基线；本版不改变游戏玩法、数据 schema 或 Launcher 迁移语义。

IndexedDB 仍为 V18、Backup 仍为 V12、HomeLayout revision 仍为 13。

推荐只使用随 Release ZIP 提供的 ASCII-only PowerShell 5.1 部署脚本。脚本会执行：

```text
ZIP SHA-256 / source identity
→ npm ci
→ npm run verify
→ clean Git preflight
→ robocopy /MIR
→ npm ci
→ npm run verify
→ release:git-working
→ git add -A
→ release:staged-check
→ git diff --cached --check
→ forbidden path check
→ commit
→ push
```

首轮验收重点：

- `coupleBoardGameService.test.ts` 14 条继续通过。
- `companionNavigation.test.ts` 不再因 `couple-board` catalog 或 revision 13 fixture 出现旧期望失败。
- 最终 Vitest 为 66 files / 563 tests。
- `vue-tsc -b`、Vite build 与 release-safety 全部通过。

最终以部署机两轮 `npm run verify` 实际输出为准。
