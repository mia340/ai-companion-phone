# V0.5.0-alpha.5.2.0 Release Manifest

## Scope

ChatRoom Generation Runtime extraction phase 1. This release moves streamed assistant placeholder lifecycle out of the Vue View without changing IndexedDB, Backup, Launcher schema, Provider fallback policy, Regex/community UI semantics, or character/memory data models.

## Runtime changes

- Added `src/runtime/generation/streamingReplyRuntime.ts`.
- Added `createStreamingReplySession()` as the canonical mutable stream-session initializer.
- Runtime now owns placeholder creation, incremental patch projection, 140 ms persistence debounce, explicit flush, discard, and interrupted-stream preservation.
- `ChatRoom.vue` supplies UI hooks for message-list projection, current streaming id and scroll requests instead of owning persistence timers.
- Final message shaping, Regex/community UI projection, state/memory side effects and Provider orchestration remain behavior-compatible for this phase.

## Regression coverage

Added `src/runtime/generation/streamingReplyRuntime.test.ts` with 7 direct cases:

1. first visible chunk creates exactly one placeholder;
2. suppressed preview does not persist partial UI payload;
3. persistence debounce stores only the latest chunk;
4. flush cancels pending debounce and persists immediately;
5. discard removes incomplete placeholder without inventing fallback content;
6. manual stop preserves already-visible real Provider output;
7. empty interrupted placeholder is removed instead of stored.

## Test matrix

- Test files: 44
- Test declarations/cases expected at runtime: 373

## Compatibility

- IndexedDB: V18 (unchanged)
- Backup: V12 (unchanged)
- Launcher: Grid V13 / HomeLayout revision 12 (unchanged)
- Provider failure policy: real error only; no local character reply fallback

## Release gate

Windows deployment must pass two complete `npm ci` + `npm run verify` gates plus Release Safety source/Git/staged checks.
