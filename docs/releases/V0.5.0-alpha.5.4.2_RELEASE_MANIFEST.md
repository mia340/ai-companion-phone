# V0.5.0-alpha.5.4.2 Release Manifest

Relationship Arc V1 TypeScript 发布热修。Windows 首轮 verify 已通过 547 条 Vitest，随后 `vue-tsc -b` 在 `SharedTimelineView.vue` 暴露可选参数访问错误 TS18048；本版本只修复该编译门禁。

## 修复

- `contextSenderLabel(senderId, event?)` 对可选 event 使用安全访问 `event?.characterName`。
- 当 sender 不在 `characterMap` 且 event 未提供时，安全回退为“角色”，不再产生 TypeScript possibly undefined 错误。

## 运行时与持久化边界

Relationship Arc V1、Shared Event provenance、AI guard、聊天草稿行为均不变。IndexedDB V18 / Backup V12 / Launcher Grid V13 / HomeLayout revision 12 不变，无数据迁移。

## 质量门禁

测试矩阵仍为 65 files / 547 tests。正式发布必须在 Windows / CI 两轮完整通过 `npm run verify`，包括 Vitest、`vue-tsc -b`、Vite Build 与 Release Safety。
