## Scope

- Fix the browser long-press timer TypeScript declaration in `src/views/HomeScreen.vue`.
- No Runtime, database, backup, prompt, UI behavior, or Community UI semantics changed.

## Root cause

The component declared `longPressTimer` as `ReturnType<typeof window.setTimeout>`. With the project's DOM + Node typings, the return type could resolve to Node's `Timeout`, while browser `window.setTimeout()` returns `number`, causing `vue-tsc` TS2322 during production build.

## Fix

```ts
let longPressTimer: number | undefined
```
