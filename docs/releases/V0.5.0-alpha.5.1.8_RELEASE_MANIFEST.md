## 本轮目标

在 alpha.5.1.7 恢复真实手机桌面的基础上，继续把主屏升级为真正的 Launcher Runtime；同时以 SullyOS·糯米机作为公开工程样本，审查并强化 Character Card 分享安全、WorldBook 输入兼容和 Memory Retrieval。

## 主要变更

### Launcher Runtime V2

- 修复主桌面左下角竖向白线 / scrollbar 泄漏；
- 横向多页 App Launcher；
- 长按 App 进入整理态；
- App 同页排序；
- 桌面与 Dock 双向拖拽；
- Dock 满 4 格时支持交换；
- 拖到左右边缘停留自动翻页；
- Widget 仍只在首页显示，Dock 固定在 Launcher 页面之外。

### Character Card Security Boundary

- 新增 `characterCardSecurity.ts`；
- import / export 双向递归净化；
- 剥离 API credential、发送者 UI / 语音偏好、组织 ID、runtime 存档残留；
- 原始社区资源继续由 Resource Archive 独立保留；
- 标准 Character Card / Character Book 字段及未知安全 extension 保留。

### WorldBook compatibility

- 新增 SullyOS-shaped entry 回归；
- `title / keysecondary / selectiveLogic / sourceUid / scanDepth / caseSensitive / matchWholeWords` 等字段映射到统一内部模型；
- `disable` 保持原意；
- unknown extension round-trip。

### Memory Retrieval V2 第一批

- `confidence` 进入检索评分；
- `hitCount` 以 capped log2 feedback 进入检索评分；
- conflict penalty 继续高于 recall boost；
- Debug reason 可解释置信度与历史召回影响。

### 文档 / 研究

- 新增 `docs/research/SULLYOS_DEEP_STUDY_2026-09-18.md`；
- 更新当前架构、项目状态、工程审查、Community Runtime、论文素材与开发日志；
- 参考 SullyOS 只学习公开架构思想与语义，本项目实现基于 Vue / Dexie 独立完成，不复制其源码 / 资源。

## 数据兼容

- IndexedDB 仍为 V18；
- Backup 仍为 V12；
- 不要求清空浏览器数据；
- 不删除旧站点；
- 桌面顺序继续使用已有 `appCustomizations` 非索引字段，不触发 schema migration。
