# V0.5.0-alpha.5.1.11 部署与更新

固定流程：**解压 → 第一次 `npm run verify` → 检查 Git 仓库干净 → robocopy → 第二次 `npm run verify` → commit → push**。

源码包：`ai-companion-phone-v0.5.0-alpha.5.1.11-windows-safe.zip`

本版不升级 IndexedDB；部署前后均不要清除浏览器站点数据。

## 真机验收重点

- 第一页左下区域不再出现竖向白线；
- 长按任意桌面 App（包括“我的资料”）都能拖动；
- App 可以落到 4×6 任意空槽位；
- App 可单独放在一页，不会被自动挤回前页；
- 拖到**手机内容区域内部**左/右边缘会换页；
- 最后一页向右拖时可临时打开新页；不放内容则新页不保存；
- 页面清空后自动消失；
- 鼠标/手指松开后拖拽 ghost、页面跟随和边缘翻页计时立即结束；
- Widget 使用合并槽位，不再占据一个独立的“上半屏布局区”；
- Dock 与底部 Home Indicator 正常。
