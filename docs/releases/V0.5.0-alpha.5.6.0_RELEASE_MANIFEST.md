# V0.5.0-alpha.5.6.0 Release Manifest

Release name: **Couple Board V1.1 / 心跳飞行棋 V1.1**

## Included

1. Custom truth/dare deck with type, intensity and mode filters; custom prompts are frozen into each game session.
2. Evidence-backed AI memory challenge generation using existing conversation memory context.
3. Strict model-output validation: exact truth/dare type, allowed evidence IDs only, compatible mode/intensity; no evidence means no generated prompt.
4. Promise/subjective/story/conflict/invalid memories are excluded from shared-memory generation evidence.
5. Six deterministic Couple Event Cards with independent pending state and heart deltas.
6. Heartbeat Highlights computed from real game history without relationship scoring or model-authored conclusions.
7. Refined dice/token/challenge/event/deck UI animations with reduced-motion support.
8. Expanded regression definitions: 67 test files / 580 declarations, including 30 Couple Board related tests.

## Memory / AI safety contract

- AI generation is user-triggered only.
- The provider sees selected stored evidence, not an unconstrained request to invent relationship history.
- Returned evidence IDs must exist in the allowed set.
- Evidence text is explicitly treated as quoted data, never as instructions; Character persona is not used as shared-history evidence.
- Generated questions remain session prompts only and never auto-write Memory / Shared Event / Relationship State.
- Chat bridging creates a local draft only; it never auto-sends.

## Release gate

```text
npm ci
npm run verify
```

Then pass Git preflight/staged safety checks and `git diff --cached --check`. Windows/CI output is authoritative.
