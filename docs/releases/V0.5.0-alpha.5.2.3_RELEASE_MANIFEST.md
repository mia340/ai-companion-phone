# V0.5.0-alpha.5.2.3 Release Manifest

## Scope

Generation Runtime phase 4. This release moves Prompt Debug lifecycle, final assistant reply persistence orchestration, and success/failure bookkeeping out of `ChatRoom.vue` while preserving real-provider-only semantics and all existing data schemas.

## Runtime changes

- Added `src/runtime/generation/promptDebugRuntime.ts`.
  - Owns Prompt Trace creation from the frozen `GenerationContext`, prompt-section/truncation/rule diagnostics, completion-time Regex/API/naturalness diagnostics, and Provider HTTP error patching.
  - Debug storage failures remain best-effort and never block a real assistant reply.
- Added `src/runtime/generation/assistantReplyPersistenceRuntime.ts`.
  - Owns the five final persistence modes: alternative, rich, canonical-display, streaming, and actions.
  - Reuses the existing Action Persistence Runtime for multi-action delivery and keeps streaming placeholder reuse consistent with Regex metadata.
- Added `src/runtime/generation/generationLifecycleRuntime.ts`.
  - Owns post-success user-message status, vision metadata, proactive timestamps, provider notices, technical-error clearing, local summary refresh, manual-stop preservation, token-limit failure and general Provider failure bookkeeping.
  - No local character-response fallback is introduced.
- `ChatRoom.vue` now delegates all three concerns and drops from about 3930 lines to about 3552 lines.
