# V0.5.0-alpha.4.3.1 部署与更新

## 1. 本地运行

```powershell
cd "D:\ai\ai-companion-phone-v0.5.0-alpha.4.3.1"
npm install
npm run verify
npm run dev
```

浏览器访问：`http://localhost:5173/ai-companion-phone/`

## 2. 本版专项验收

- `npm run verify` 应先显示 **30 files / 275 tests 全部通过**，随后执行 `vue-tsc -b && vite build` 并成功生成 `dist`。
- 重新导入或编辑褚焚川角色卡时，`姜阮,女,23岁(生日12月3日),168cm...` 应识别出：姓名姜阮、性别女、年龄23、身高168cm。
- 朋友圈评论串与多人回复功能应保持 alpha.4.3 行为不变。

## 3. 同步正式 Git 工作区

```powershell
cd "D:\ai"
robocopy ".\ai-companion-phone-v0.5.0-alpha.4.3.1" ".\ai-companion-phone-git-clean" /E /XD .git node_modules dist /XF "*.tsbuildinfo" /R:2 /W:1
cd ".\ai-companion-phone-git-clean"
npm install
npm run verify
git diff --check
git status
```

确认全绿后：

```powershell
git add -A
git commit -m "fix: parse parenthesized persona age in creator notes"
git push origin main
```

GitHub Actions 会自动执行 `npm ci`、`npm test`、`npm run build` 并部署 GitHub Pages。测试不通过时不会部署。
