# V0.5.0-alpha.5.7.1 Release Manifest

Release name: **Couple Board V1.2.1 / field-test hotfix**

## Included

1. Removes the generic `PlaceholderApp` route and the placeholder view itself. Unknown/obsolete routes now return to Home instead of showing a fake “later” app screen.
2. Strengthens PWA update behavior: launch-time service-worker update check, immediate waiting-worker refresh, and outdated-cache cleanup.
3. Character selection supports native horizontal touch scrolling plus pointer/mouse drag and wheel scrolling; the setup UI explicitly tells users when more partners are available off-screen.
4. Dice animation is bounded and is separated from IndexedDB/archive persistence. Exceptions and slow saves cannot leave the die spinning forever.
5. Built-in Couple Board prompt library expands from 64 to **128** curated prompts: 16 Truth + 16 Dare prompts at each of L1/L2/L3/L4. L4 remains adult-only, non-explicit, consent-first.
6. The content center opens on the system library by default and the setup card exposes the real built-in prompt count so an empty custom library no longer looks like an empty game.
7. Release safety now audits every launcher app route plus the finished native-app routes, and fails if the old generic placeholder route or fallback behavior returns.
