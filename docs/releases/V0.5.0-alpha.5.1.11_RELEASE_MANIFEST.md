## 本版目标

针对真机/桌面浏览器反馈，将 Launcher 从“分页列表”升级为真正的 **4×6 Home Grid**：

1. 定位并删除左侧竖白线的真实来源：默认壁纸底部的 `filter: blur()` 装饰光斑在 Chromium 合成层边界产生 2px 裁切缝；本版移除独立 blur 光斑 DOM，改为单层背景渐变；
2. 每页固定 4 列 × 6 行槽位，App 占 1×1；小组件使用 2×2 / 4×2 等合并槽位；
3. App 坐标和页面归属写入 `homeLayoutPages`，允许一个 App 单独待在一页，不再由“容量切片”强制重排；
4. 页面不能手工空建：拖拽 App 到最后一页右侧手机内边缘时临时出现新页；真正放入内容后才持久化；空页自动回收；
5. 左右翻页热区严格使用手机内容视口左右边缘，不要求把鼠标/手指拖到手机外；
6. Pointer 生命周期改为 window 级 `pointermove / pointerup / pointercancel / blur` 收尾，松开鼠标后 ghost 与页轨道必须立即结束；
7. `我的资料` 与所有桌面 App 使用相同的 Grid Item 路径，可自由移动、换页、与其他 1×1 App 换位。

## 数据兼容

- `homeLayoutPages` 继续写入既有 `appCustomizations` 非索引记录，不升级 Dexie schema；
- 旧 `homePageKeys` / `homeAppKeys` 自动转换为 4×6 网格；
- 旧页面归属尽量保留；没有新布局字段的旧数据无需清站点数据；
- IndexedDB 仍为 V18，Backup 仍为 V12。
