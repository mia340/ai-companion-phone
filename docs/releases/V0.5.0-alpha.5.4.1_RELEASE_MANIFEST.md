# V0.5.0-alpha.5.4.1 Release Manifest

Relationship Arc V1 发布热修。修复 Windows 首轮 verify 暴露的两个 provenance / projection 回归，不增加新功能。

## 修复

- `buildRelationshipArc()` 在 Shared Event projection 前先按 event owner 收窄，并再次按 evidence `characterId` 过滤，防止异常或陈旧 event wrapper 把另一角色证据带入当前 Arc。
- `projectSharedTimelineEvents()` 在 projection 仍保留完整 evidence 集合时继续使用原稳定 `evidenceKey`；只有 evidence 被隐藏/筛除、provenance 集合变化时才使用重算 key。这样用户已确认事件摘要可稳定命中，同时证据变化后仍会自动失效。

## 运行时与持久化边界

Relationship Arc V1、AI provenance guard、带回聊天草稿行为均不变。IndexedDB V18 / Backup V12 / Launcher Grid V13 / HomeLayout revision 12 不变，无数据迁移。

## 质量门禁

测试矩阵仍为 65 files / 547 tests。正式发布必须在 Windows / CI 两轮完整通过 `npm run verify`，包括 Vitest、`vue-tsc -b`、Vite Build 与 Release Safety。
