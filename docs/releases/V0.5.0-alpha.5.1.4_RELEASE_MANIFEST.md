# V0.5.0-alpha.5.1.4 · 伴信入口整合与个性签名

- 桌面只显示一个「伴信」社交入口；原聊天、通讯录、朋友圈历史路由继续兼容，钱包原本是占位功能，现进入「我」→「钱包」可看明确状态。
- 伴信遵循微信的信息架构，四个底部入口：聊天、通讯录、发现、我。朋友圈作为「发现」里的功能；钱包作为「我」里的功能。聊天及朋友圈未读数显示在对应标签上。
- 「我」展示昵称、头像、独立的个性签名。资料编辑可填写最多 80 字的签名；朋友圈封面下显示该签名。
- 签名独立于 bio / Persona，不被当成角色事实注入 Prompt；旧用户无需迁移数据库列，字段可选，原备份继续兼容。
- 不改动原有聊天、角色卡、世界书及 AI 生成边界。微信作为信息架构与交互体验的参考，不使用微信名称或商标。
- 钱包尚无真实账户、支付、转账功能；新版只整合入口与诚实状态页，不宣称实现资金功能。
