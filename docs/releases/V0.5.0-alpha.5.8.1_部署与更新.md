# V0.5.0-alpha.5.8.1 · 部署与专项验收

## 部署

使用同版本 `*-windows-safe.zip` 与 `deploy-v0.5.0-alpha.5.8.1-ps51-safe.ps1`。脚本会先在解压源码跑 Gate 1，再同步到 `D:\ai\ai-companion-phone-git-clean`，随后跑 Gate 2、staged safety、commit 和 push。

## 本轮专项验收

1. 开局页面不再提供聊天/面对面切换；默认明确显示“面对面互动”。
2. 任意角色掷骰落到花店、公园、电影院等地图格后，角色只能把它当“棋盘格”，不能说双方现实正在该地点。
3. 实际地点若用户没有明确说明，角色不得自行猜“房间/酒店/家里”；若用户明确说出，可按真实上下文继续。
4. 打开题卡后默认仍能看到地图上半部；拖动顶部横条可收起/展开，“看地图”可快速收至低档，顶部返回键始终可用。
5. 对话气泡只靠左右位置与头像区分，不再重复显示角色姓名。
6. 谁掷骰，当前题就只属于谁。另一方必须能回应并继续互动，但系统题和 Memory AI 题都不能要求双方各答一次或共同承担同一道任务。
7. 结束一段真实互动后检查 Memory：真实说过的话可进入长期记忆，但“花店/床边”等棋盘地点不得被写成现实共同经历。
8. 连续测试用户回合和角色自动回合，确认角色仍会自动掷骰、逐格移动、题后互动可多轮延长。
