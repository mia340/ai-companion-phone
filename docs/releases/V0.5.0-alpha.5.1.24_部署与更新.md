# V0.5.0-alpha.5.1.24 部署与更新

部署包：`D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.24-windows-safe.zip`

本版本是 alpha.5.1.23 的 Windows ZIP 打包兼容热修版：修复历史中文文件名的 ZIP 编码，确保 PowerShell `Expand-Archive` 可正常解压。

部署要求：

1. 先校验 ZIP SHA-256。
2. 解压后校验 `package.json` 版本，并确认旧 `pageDiagnosticLine()` 不存在。
3. ZIP 解压目录执行 `npm ci` 与 `npm run verify`。
4. Git 仓库必须保持 clean 且分支为 `main`。
5. `robocopy /MIR` 同步时排除 `.git`、`node_modules`、`dist`。
6. Git 仓库再次执行 `npm ci` 与 `npm run verify`。
7. 两轮 verify 全部通过后才允许 commit / push。
