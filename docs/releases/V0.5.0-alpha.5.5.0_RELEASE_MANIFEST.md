# V0.5.0-alpha.5.5.0 Release Manifest

Release name: **Couple Board V1 / 心跳飞行棋**

## Included

1. Native `/app/心跳飞行棋` route and `CoupleBoardView.vue`.
2. `couple-board` Launcher App key, custom icon and HomeLayout revision 13 migration.
3. `coupleBoardGameService.ts`: 30-cell board, turn/movement rules, heart score, challenge lifecycle and local persistence.
4. 64 built-in truth/dare prompts across L1–L4 and chat/reality modes.
5. Adult-mode guard: explicit 18+ confirmation plus hard block for a character whose known age is below 18.
6. Consent-first challenge actions: complete / replace / skip; reality prompts never imply automatic consent.
7. Chat bridge writes only a draft to the latest real single conversation; no automatic send and no Memory/Relationship side effects.
8. Resume/rematch flow using the existing `appCustomizations` store; no new IndexedDB store.
9. 14 new Couple Board service tests + 2 Launcher migration tests.

## Release gate

The package must pass, twice (extracted source and clean Git repo):

```text
npm ci
npm run verify
```

Then it must pass `release:git-working`, `release:staged-check`, `git diff --cached --check`, forbidden staged path checks, commit, and push.

The artifact-generation environment did not have a complete npm dependency cache, so this manifest does **not** claim a completed local 66/563 Vitest run. Windows/CI output is authoritative.
