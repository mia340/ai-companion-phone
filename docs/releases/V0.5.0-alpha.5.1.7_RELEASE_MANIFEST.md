# V0.5.0-alpha.5.1.7 Release Manifest

发布日期：2026-09-18

## 版本

- App：0.5.0-alpha.5.1.7
- IndexedDB：V18（不变）
- Backup：V12（不变）

## 本轮范围

- 恢复空间桌面的音乐、海龟汤入口。
- 恢复四格底部 Dock。
- 主屏改为四列 App 网格，并移除常驻长按提示文案。
- 长按空白处进入桌面编辑态：添加小组件 / 自定义 / 编辑墙纸 / 编辑页面 / 完成。
- 新增 Widget Catalog V1：今天、最近的人、世界状态、一起听。
- Widget 支持通透 / 毛玻璃 / 实色材质。
- 玩家可自定义桌面 App、Dock、Widget、壁纸、图标、图标大小和名称显示。
- 桌面布局复用 `appCustomizations`，不升级数据库。
- 同类设计研究归档到 `docs/research/HOME_WIDGET_CUSTOMIZATION_STUDY_2026-09-18.md`。

## 安全 / 数据

- 从桌面移除 App 只隐藏 Launcher 入口，不删除路由或数据库数据。
- 不清除 IndexedDB、LocalStorage 或浏览器站点数据。
- 旧 alpha.5.1.6 用户升级后，缺失的新布局字段会自动使用 alpha.5.1.7 默认值，因此音乐、海龟汤和 Dock 会重新出现。

## 验证

- Windows 首次验证：37 个测试文件 / 308 个测试全部通过，随后 `vue-tsc` 发现桌面自定义持久化字段仍以 `string[]` 存储，而运行时已经收窄为 `HomeAppKey[] / HomeWidgetKey[]`。
- R3 修正：加载存储记录时先按 `unknown` 接收，再通过 `normalizeHomeAppearance()` 白名单收窄；保留旧 IndexedDB 数据兼容，不升级数据库。
- R3 仍需在 Windows / CI 完整执行 `npm run verify`，只有 Vitest + vue-tsc + Vite build 全部成功后才能部署。
