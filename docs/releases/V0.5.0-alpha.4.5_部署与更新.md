## 本轮专项验收

1. 使用默认 Persona“我”的旧聊天继续生成一轮：无明确第三人称规则时，旁白应使用“你”，不再用“她/女生”指代当前用户。
2. Prompt Debug 应出现“叙事人称锁”，并能看到默认 Persona“我”被说明为 UI 显示名而非世界内姓名。
3. 打开包含 `{{user}}某某设定 + <user_profile>` 的旧角色 → 角色卡；即使当初未保存 `embeddedUserTemplate`，现在也应能从已绑定 Lorebook 恢复角色专属 Persona 预览。
4. 若原卡/世界书/Prompt 预设明确要求第三人称叙事，则该作者规则仍优先，不强制改成第二人称。
