# V0.5.0-alpha.5.8.0 · 部署与更新

本版是 **心跳飞行棋 V2.0 Alpha 沉浸互动重构**。它不升级 IndexedDB / Backup / Launcher schema，重点把角色连续性、长期 Memory、双向自由互动、角色自动掷骰和主题地图打通。

## 部署前

建议先在应用内导出一次 Backup。不要清浏览器站点数据，不要手工删 IndexedDB。

把当次发布 ZIP 与 `deploy-v0.5.0-alpha.5.8.0-ps51-safe.ps1` 放到：

```text
D:\ai
```

PowerShell：

```powershell
cd D:\ai

$zip = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.8.0-windows-safe.zip"
$script = "D:\ai\deploy-v0.5.0-alpha.5.8.0-ps51-safe.ps1"

Get-FileHash $zip -Algorithm SHA256
Get-FileHash $script -Algorithm SHA256

powershell -NoProfile -ExecutionPolicy Bypass -File $script
```

脚本会依次执行：解压 → Gate 1 `npm run verify` → Git preflight → 同步源码 → Gate 2 `npm run verify` → staged safety → commit → push。

如果最后只是 `github.com:443` 网络失败，但已经打印 `Local release commit exists`，不要重跑部署脚本；恢复网络后只执行：

```powershell
cd D:\ai\ai-companion-phone-git-clean
git push origin main
```

## V2 专项验收

按下面顺序走一遍即可覆盖本轮最重要的主链：

1. 打开心跳飞行棋，确认顶部显示 `COUPLE BOARD · V2.0 ALPHA`。
2. 选择任意角色；横向角色栏可以滑动，点击角色有效。
3. 选择“像素约会”，开始一局；确认地图不是旧方格，而是带地点名的约会路线。
4. 用户掷骰：骰子有限时间停止；自己的像素小人按实际步数逐格移动。
5. 轮到角色：不要点骰子；确认角色会自行掷骰并移动。
6. 抽到用户先答的题：输入回答后角色必须回应；只有双方都回应过，才允许“这段聊够了 · 继续走”。
7. 继续在同一道题里多聊 2-3 轮，确认不会被游戏进度强制截断。
8. 如果角色自然收尾，确认显示“我还想继续”，并且点后可以继续当前互动。
9. 结束互动，到 Memory Center 检查本局真实互动已进入长期 Memory；随后回普通聊天，相关话题应可被后续检索。
10. 刷新正在进行的一局再“继续”，确认棋子位置和未关闭 Interaction 都能恢复。
11. 新开一局改成“浪漫地图”，确认只是表现变化，数据和玩法不重置。
12. L4/L5 仍需显式 18+ 确认；年龄明确小于 18 的角色必须硬阻断。
