# V0.5.0-alpha.5.4.0 Release Manifest

Relationship Arc V1：在 Shared Event Runtime 上新增证据驱动的关系脉络视图、明确 relationship state 阶段、严格 provenance 的 AI 脉络摘要，以及用户主动“带回聊天草稿”。

## 运行时边界

- Runtime 不根据普通文案猜测关系方向、冲突、和解或感情程度。
- 只有来源本身明确的 promise / relationship / goal / story / shared-event signal 参与节点分类。
- 只有 `ConversationStateHistory(field=relationship)` 的真实 before/after 能形成明确关系状态阶段。
- AI 必须回传完整 `characterId + arcFingerprint + nodeIds + evidenceIds`；候选只有用户确认后才保存。
- 关系脉络不会自动写入 Memory、Conversation State 或角色 Prompt。
- “带回聊天”只写草稿，不自动发送。

## 持久化

继续复用 `appCustomizations.sharedTimelineState` 非索引字段，仅新增 `relationshipArcSummaries` 用户确认元数据。IndexedDB V18 / Backup V12 / Launcher Grid V13 / HomeLayout revision 12 均不变，无数据迁移。

## 质量门禁

静态测试定义：65 files / 547 tests。正式发布必须在 Windows / CI 两轮完整通过 `npm run verify`，包括 Vitest、`vue-tsc -b`、Vite Build 与 Release Safety。
