## 数据升级

首次打开后 IndexedDB 自动从 V17 升级到 V18：

- `socialProfiles`：角色朋友圈权限 / 活跃度；
- `socialNotifications`：朋友圈本地未读互动。

无需清数据库。

Backup 从 V11 升级到 V12，并继续读取 V1—V11 旧备份。

## 手动验收

1. 朋友圈右上角 `•••` 打开设置。
2. 给不同角色设置“安静 / 自然 / 活跃”，并单独关闭某位角色的评论或接话。
3. 发一条朋友圈，确认关闭评论权限的角色不会自动评论；开启角色仍能互动。
4. 回复角色评论，确认“可以接话”打开时角色继续回复，关闭时不排后台回复。
5. 角色评论你的动态后，确认朋友圈顶部出现未读数量，回主屏幕后朋友圈图标也有角标。
6. 打开“新互动”，点击一条通知，应滚动到对应动态。
7. 开启“好友自主动态”后，关闭某角色“可以主动发动态”，确认后台不会选该角色主动发布。
