# V0.5.0-alpha.5.3.2 部署与更新

本版本为 **「时光 / 共同回忆」V1.2 · 共同事件**。不升级 IndexedDB、Backup 或 Launcher HomeLayout revision，不需要清站点数据。

## 新功能验收

- 时光默认进入“事件”视图；可切换回“证据”视图。
- 同一真实来源的记忆/状态以及短时间内相关的图片、动态等可合并为一个共同事件。
- 点“查看事件”可看到事件详情、图片画廊与完整 evidence chain；每条证据都能回原聊天/朋友圈。
- 证据视图可进入“合并证据”，选择至少两条同角色 evidence 后手工合并并命名。
- 人工事件可以改标题、收藏、隐藏、拆分；拆分不会删除原始证据。
- 主动旧事使用事件级 guard，Prompt 同时携带 event id 与 evidence ids。
