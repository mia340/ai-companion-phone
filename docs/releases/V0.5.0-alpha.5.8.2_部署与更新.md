# V0.5.0-alpha.5.8.2 部署与更新

把 ZIP 与 `deploy-v0.5.0-alpha.5.8.2-ps51-safe.ps1` 放到 `D:\ai`，使用 PowerShell 5.1-safe 脚本部署。

部署脚本会执行 Gate 1、同步 Git 工作区、Gate 2、staged safety check、commit 与 push。若最后仅 GitHub 网络 push 失败，不要重跑整个部署；网络恢复后在 Git 仓库执行 `git push origin main`。

本版重点人工验收：

- 题目出现后，地图始终占上半屏，互动始终占下半屏。
- 页面没有“看地图 / 展开 / 收起 / 换一题”。
- 用户题点击“请求跳过”后，角色必须明确同意才会跳过。
- 角色题只有角色自己提出跳过后，用户才看到“同意跳过 / 继续这题”。
- 任何现实身体互动仍可直接拒绝或停止，顶部返回仍可结束整局。
