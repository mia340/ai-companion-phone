# V0.5.0-alpha.5.1.10 Release Manifest

日期：2026-09-18  
App：0.5.0-alpha.5.1.10  
IndexedDB：V18  
Backup：V12

## 本版目标

针对 Launcher 真机反馈完成第三轮修正：

1. 删除原生横向 scroll 分页路径，避免左侧竖白线/浏览器边缘指示；
2. 支持触屏与鼠标直接左右拖动翻页；
3. 页面数量完全由内容决定，至少一页；
4. App 溢出容量自动产生下一页，页面清空自动回收；
5. 取消人工“新增一页 / 删除一页”；
6. 保留跨页拖动后的非空页归属和固定四格 Dock。

## 兼容性

- 不升级 IndexedDB schema，仍为 V18；
- Backup 仍为 V12；
- 旧 `homePageKeys` 中的人为空页在读取/保存时自动清理；
- 不清除 IndexedDB / LocalStorage / 浏览器站点数据。

## 验收门禁

Windows 部署前必须两次执行 `npm run verify`。当前源码静态定义 38 个测试文件 / 317 个测试声明；最终通过数量以 Windows 实际 Vitest 输出为准。
