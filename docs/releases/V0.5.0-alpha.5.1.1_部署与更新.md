# Windows 部署 V0.5.0-alpha.5.1.1

1. 将 `ai-companion-phone-v0.5.0-alpha.5.1.1-windows-safe.zip` 下载到 `D:\ai`。
2. 使用 PowerShell 解压到新的 `D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.1`，检查 `package.json` 存在。
3. 运行 `npm install`、`npm run verify`；测试及 build 均成功后再 `npm run dev` 测试封面上传、恢复默认、独立通知和设置页面。
4. 确认 Git 工作树无需要保留的更改，再复制项目到 `D:\ai\ai-companion-phone-git-clean`（排除 `.git`、`node_modules`、`dist`），在 Git 目录重新执行 `npm ci` 和 `npm run verify`，再提交推送。

现有 IndexedDB V18、Backup V12 不变，不要清除站点数据或删除旧聊天。PWA 若显示旧界面，检查部署 Actions 通过后关闭旧页面并重新打开；不要为了更新而清站点数据。
