## 功能冒烟

1. 内容中心新增/编辑一条题和一张“再掷一次”事件卡；回到开局可看到数量更新。
2. 开局后再编辑全局题库，当前局仍使用开局冻结快照。
3. 系统题/事件可逐条停用；即使某类全部禁用，对应格也不会崩溃。
4. AI 回忆题可使用 Memory 或当前角色 Shared Timeline 的 factual evidence；promise/goal/story 不进入候选。
5. 完成一局后内容中心“回忆册”新增且刷新不重复；删除只删游戏历史，不改聊天/记忆。
6. 聊天模式结束后“分享结算”只进入聊天草稿，用户自己发送。
7. L4 仍要求 18+ 显式确认；已知未成年角色仍被 Runtime 阻断。
8. 题库 JSON 导出/导入能还原自定义题、事件卡和系统启停偏好。
