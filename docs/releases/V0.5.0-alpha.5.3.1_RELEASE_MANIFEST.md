# V0.5.0-alpha.5.3.1 Release Manifest

## Scope

Feature release: **时光 / 共同回忆 V1.1**. It extends the evidence-backed timeline with search, date browsing, media evidence and a guarded proactive-recall bridge back into chat.

## Feature surface

- Search across title, summary, character, source excerpt and media label.
- Time filters: recent 30 days, same calendar day in prior years, and earliest evidence per character.
- Month grouping for the timeline list.
- Image evidence from chat image messages and Moment images.
- Music evidence from real `Message.type === 'music'` rows; no track title is invented when history does not contain one.
- AI milestone proposals operate only on the currently visible/filtered evidence set.
- Proactive chat may lazily receive one verified old timeline evidence item after normal proactive timing gates pass; mentioning that old event is constrained to the supplied evidence id.

## Safety / truth boundary

- Hidden timeline items are never eligible for proactive recall.
- Recall evidence must belong to the current character and be at least 7 days old.
- Starred evidence is preferred; then higher importance; then recency.
- Timeline lookup failure is fail-soft and cannot prevent chat from loading.
- Provider failure policy is unchanged: no local role-reply fabrication.

## Persistence

- No new IndexedDB store.
- IndexedDB V18 unchanged.
- Backup V12 unchanged.
- Launcher Grid V13 / HomeLayout revision 12 unchanged.

## Test matrix

Windows deployment must pass two full `npm ci` + `npm run verify` gates. Both test runs must report 56 files / 469 tests, followed by successful `vue-tsc -b`, Vite build and Release Safety checks.
