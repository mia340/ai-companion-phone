# V0.5.0-alpha.5.3.4 Release Manifest

## Scope

**时光 V1.3 · Event Intelligence**. This release upgrades Shared Event from grouping-only to evidence-bound event intelligence while keeping the local-first provenance boundary.

## Features

- Event-level AI summary proposal with strict `event id + complete evidence ids` verification.
- User-confirmed summaries are persisted only after explicit acceptance and automatically become stale when the event evidence set changes.
- User event notes stored as metadata keyed by stable evidence fingerprint; notes are not injected into role prompts.
- Real chat context windows around each source message, with conversation isolation and recalled-message filtering.
- Manual evidence ordering in event details. Reordering an auto event converts it to a manual event without copying evidence bodies.
- Proactive timeline recall can use a still-valid user-confirmed event summary while retaining the event/evidence provenance guard.

## Persistence

- IndexedDB V18 unchanged.
- Backup V12 unchanged.
- Launcher Grid V13 / HomeLayout revision 12 unchanged.
- `appCustomizations.sharedTimelineState` adds non-indexed `eventNotes` and `eventSummaries`; no migration or site-data reset is required.

## Test matrix

- Expected test files: 59

- New coverage: stable evidence fingerprint, manual order, summary staleness, event-level recall summary, source-message context windows, and strict event-insight parsing.
