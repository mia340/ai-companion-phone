# V0.5.0-alpha.5.5.2 部署与更新

本版本是心跳飞行棋 V1 的 Launcher 测试夹具热修。5.5.1 Windows 首轮 verify 已达到 65/66 个测试文件、562/563 条测试；唯一失败来自 `companionNavigation.test.ts` 中一个重复 `homeLayoutRevision` 键。

该对象前面已经写入当前 revision 13，末尾却残留 `homeLayoutRevision: 7`；后键覆盖前键后，测试误触发真实旧布局迁移并自动补入 `couple-board`。5.5.2 只删除这个旧键，同时消除 Vite/esbuild duplicate-key warning。

IndexedDB 仍为 V18、Backup 仍为 V12、HomeLayout revision 仍为 13；游戏 Runtime、UI、题库、成人模式边界和真实 revision 12 → 13 迁移均不变。

推荐只使用随 Release ZIP 提供的 ASCII-only PowerShell 5.1 部署脚本。脚本执行：

```text
ZIP SHA-256 / source identity
→ npm ci
→ npm run verify
→ clean Git preflight
→ robocopy /MIR
→ npm ci
→ npm run verify
→ release:git-working
→ git add -A
→ release:staged-check
→ git diff --cached --check
→ forbidden path check
→ commit
→ push
```
