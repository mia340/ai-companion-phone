# V0.5.0-alpha.5.1 Release Manifest

版本：`0.5.0-alpha.5.1`
日期：2026-09-16
主题：Social Runtime V2 / 朋友圈社交决策层

## 本版新增

- 每角色朋友圈权限：看、赞、评、回、主动发动态。
- 每角色互动频率：安静 / 自然 / 活跃。
- 朋友圈候选角色从“均匀随机”升级为可解释加权选择：最近聊天、共享记忆、内容相关性、互动冷却。
- 非 AI 点赞任务；评论与点赞权限独立。
- 朋友圈新互动通知、未读计数、主屏幕朋友圈角标。
- 微信式简洁朋友圈头部、发布菜单、底部设置面板和通知面板。
- 角色删除 / 动态删除同步清理相关 Social Profile / Notification。

## 数据兼容

- IndexedDB：V18（新增 `socialProfiles` / `socialNotifications`）
- Backup：V12（新增 `socialProfiles`；运行时队列与未读通知不进入备份）
- 既有角色、聊天、Persona、世界书、朋友圈动态与评论均保留。

## 测试定义

- 33 个 `*.test.ts`
- 296 个静态测试声明
- 新增 `socialPresenceService.test.ts`，覆盖权限、相关性、关系新鲜度、冷却、活跃度权重、无重复加权抽样。

完整 `npm run verify` 仍以 Windows / CI 实际执行结果为发布门禁。
