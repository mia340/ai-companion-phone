# V0.5.0-alpha.5.3.0 Release Manifest

## Scope

Feature release: native **时光 / 共同回忆 V1**. It adds an evidence-backed shared timeline without introducing a new IndexedDB store or changing existing canonical Memory / Moment / Conversation State data.

## Feature surface

- New `SharedTimelineView.vue` native App at `/app/时光`.
- Timeline evidence sources: meaningful CharacterMemory records, Moments, and `event / relationship / goal` state-history rows that carry a source message.
- User controls: character filter, star, hide/unhide, custom title, exact source navigation.
- Chat deep link: `/chat/:id?message=:messageId` scrolls to the evidence message.
- Launcher key/icon: `timeline`; fresh installs include it in the default Home app set, existing persisted layouts remain canonical and can add it through Launcher editing.
- Memory Center exposes a direct “时光” shortcut.

## AI evidence policy

- AI receives only a bounded evidence list and may select at most 5 existing IDs.
- Runtime rejects unknown IDs, duplicates, invalid JSON and empty titles.
- AI suggestions do not modify source facts and are not persisted automatically.
- User must explicitly choose “采用标题并收藏” before the suggested title/star is stored.

## Persistence

- `appCustomizations.sharedTimelineState` stores only `starredIds`, `hiddenIds`, and `customTitles`.
- Canonical evidence remains in Memory / Moment / Conversation State History.
- IndexedDB V18 unchanged.
- Backup V12 unchanged; generic AppCustomization backup already carries the new non-indexed field.
- Launcher Grid V13 / HomeLayout revision 12 unchanged.

## Test matrix

- Expected test files: 54
- Expected test declarations/cases: 453
- New direct tests: 13

## Release gate

Windows deployment must pass two full `npm ci` + `npm run verify` gates. Both test runs must report 54 files / 453 tests, followed by successful `vue-tsc -b`, Vite build and Release Safety checks.
