# V0.5.0-alpha.5.9.0 部署与更新

把 ZIP 与 `deploy-v0.5.0-alpha.5.9.0-ps51-safe.ps1` 放到 `D:\ai`，不要手工覆盖 Git 仓库。

```powershell
cd D:\ai
$zip = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.9.0-windows-safe.zip"
$script = "D:\ai\deploy-v0.5.0-alpha.5.9.0-ps51-safe.ps1"
Get-FileHash $zip -Algorithm SHA256
Get-FileHash $script -Algorithm SHA256
powershell -NoProfile -ExecutionPolicy Bypass -File $script
```

脚本会执行两轮 `npm ci + npm run verify`、release safety、Git staged check、commit 与 push。若最后只有 `git push origin main` 因网络失败，且本地 commit 已创建，不要重跑整个脚本；恢复网络后只执行 `git push origin main`。
