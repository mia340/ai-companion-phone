# 心跳飞行棋 · 题库 V3（160 题）

> V0.5.0-alpha.5.7.4 / Couple Board V1.4.0

结构：5 档 ×（16 真心话 + 16 大冒险）= 160 题。L4/L5 都走 18+ 门禁；明确未成年角色硬阻断。所有挑战仍可换题或跳过。
