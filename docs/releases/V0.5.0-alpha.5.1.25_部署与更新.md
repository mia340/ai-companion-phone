# V0.5.0-alpha.5.1.25 部署与更新

部署包：`D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.25-windows-safe.zip`

本版本是 Launcher 幽灵页真机热修：修复「今天」Widget CSS 类名碰撞，并强化 near-zero DOM painted 判定。

部署要求：

1. 校验 ZIP SHA-256。
2. 解压后确认 `package.json` 版本为 `0.5.0-alpha.5.1.25`。
3. ZIP 解压目录执行 `npm ci` 与 `npm run verify`。
4. Git 仓库必须 clean 且分支为 `main`；若存在 ignored-but-tracked 文件必须先停止。
5. `robocopy /MIR` 同步时排除 `.git`、`node_modules`、`dist`。
6. Git 仓库再次执行 `npm ci` 与 `npm run verify`。
7. 两轮 verify 全部通过后才允许 commit / push。

验收重点：

- 新增「今天」Widget 时应以正常 4×2 尺寸显示，不得退化为 1×1。
- 历史视觉幽灵页若项目 proof 退化到近零尺寸，应在连续确认后按 recovery-safe 路径回收。
