## 2. 本轮专项验收

### Persona

重新导入带 `[用户设定...]` creator_notes 的角色卡时，创建页应直接识别角色专属 Persona（褚焚川样本应识别“姜阮”），默认勾选随角色创建并绑定。对于已经存在的角色，进入其 Character Card Editor，应出现从 creator_notes 恢复出的用户模板，可点击“创建并绑定角色专属 Persona”，无需删除旧聊天。之后在“我的资料”中应看到对应角色专属 Persona。

### 朋友圈

准备至少 3 个当前世界角色，回复热度选择“热闹”。用户发一条动态后，候选足够时应有 2～3 位不同角色参与；点按任一角色评论，输入区应显示“回复 XX”，发送后应显示“我 回复 XX：……”，该角色随后可显示“XX 回复 我：……”。如果当前世界只有 1 个角色，当然最多只能有 1 位角色互动。

当前首次自动互动仍由朋友圈页面内 timer 调度，因此专项验收时先停留在朋友圈页面等待反应；离开页面会取消尚未触发的初始反应，这是后续 Social Activity Queue 的待办，而不是本轮 DB 问题。

## 4. 同步正式 Git 工作区与部署

```powershell
cd "D:\ai"
robocopy ".\ai-companion-phone-v0.5.0-alpha.4.3" ".\ai-companion-phone-git-clean" /E /XD .git node_modules dist /XF "*.tsbuildinfo" /R:2 /W:1

cd ".\ai-companion-phone-git-clean"
npm install
npm test
npm run build
git diff --check
git status
```

确认全部通过后：

```powershell
git add -A
git commit -m "feat: threaded moments replies and embedded user persona import"
git push origin main
```

仓库 `.github/workflows/deploy.yml` 会在 `main` push 后执行 `npm ci` → `npm test` → `npm run build`，并把 `dist` 上传 GitHub Pages。
