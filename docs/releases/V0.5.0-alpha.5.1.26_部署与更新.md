# V0.5.0-alpha.5.1.26 部署与更新

本版本只收口发布链安全，不修改 IndexedDB、Backup Schema、聊天/角色/记忆 Runtime 或桌面布局 Schema。

发布流程继续执行“双验证”：

1. 校验 ZIP 身份和 SHA-256。
2. 解压后执行 `npm ci` 与 `npm run verify`。
3. 同步前用新包内的 `release-safety.mjs git-preflight <repo>` 检查目标仓库，必须为 main、存在 origin、clean 且无 ignored-but-tracked 污染。
4. 同步源码，排除 `.git`、`node_modules`、`dist`、`*.tsbuildinfo`。
5. Git 仓库再次执行 `npm ci` 与 `npm run verify`。
6. 执行 `npm run release:git-working`。
7. `git add -A` 后执行 `npm run release:staged-check`。
8. 只输出短 diff 摘要，然后 commit / push。

任何安全检查失败都必须停止，不得跳过门禁提交。
