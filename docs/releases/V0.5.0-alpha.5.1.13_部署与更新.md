# V0.5.0-alpha.5.1.13 部署与更新

继续使用 **IndexedDB V18 / Backup V12**。不要清除浏览器站点数据。

固定门禁：**解压 → `npm ci` → `npm run verify` → 检查 Git 工作树 → robocopy → 第二次 `npm ci && npm run verify` → commit → push**。任一 verify 失败立即停止。

## 本版专项验收

1. 拖动一个 App 插到两个 App 之间时，后面的图标连续后移，而不是两者交换；
2. Widget 与 App 之间也使用同一套动态重排，组件尺寸会真实挤开多个格子；
3. 拖动过程中即可看到周围图标滑动让位，松手后才保存；
4. 来源页产生空洞时只在本页向前补位，不会把下一页内容擅自拉回来；
5. 目标页满时，尾部内容可继续推到下一页；单 App 独占页面仍可保留；
6. 取消拖拽或 pointercancel 时预览回滚，不写入数据库。
