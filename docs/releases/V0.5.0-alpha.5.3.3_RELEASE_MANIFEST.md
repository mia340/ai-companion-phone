# V0.5.0-alpha.5.3.3 Release Manifest

## Scope

Hotfix release for **时光 V1.2 / Shared Event Runtime**. The 5.3.2 implementation was correct, but one proactive-recall regression test asserted an older singular Chinese phrase while the runtime now emits the stricter multi-evidence wording “这些证据”.

## Fix

- No production runtime behavior change.
- `proactiveMessageService.test.ts` now verifies the invariant semantically: the instruction must contain both “不要补写” and “没有发生过的情节”.
- The test still separately verifies `event id` and the complete `evidence ids` list, so the provenance guard remains locked.
- This avoids false failures caused only by singular/plural wording while preserving the actual hallucination-prevention requirement.

## Persistence

- IndexedDB V18 unchanged.
- Backup V12 unchanged.
- Launcher Grid V13 / HomeLayout revision 12 unchanged.
- No migration or site-data reset required.

## Test matrix

- Expected test files: 57
- Expected tests: 481
- Runtime behavior is unchanged from 5.3.2; only the brittle assertion is corrected.

## Release gate

Windows deployment must pass two full `npm ci` + `npm run verify` gates. Both runs must report 57 files / 481 tests, followed by successful `vue-tsc -b`, Vite build and Release Safety checks.
