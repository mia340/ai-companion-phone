# V0.5.0-alpha.5.7.1 部署与更新

这是 5.7.0 的现场测试热修：处理旧占位页、搭档列表无法拖动、内置题库不够显眼/数量不足，以及骰子动画可能一直转的问题。数据层不升级：IndexedDB V18、Backup V12、Launcher Grid / HomeLayout revision 13 均不变。

## 首轮验收重点

- 直接刷新并重新进入「音乐 / 海龟汤 / 时光 / 心跳飞行棋 / 朋友圈」时，不应再看到“桌面入口和页面容器已经搭好”的占位页；未知旧路由应回桌面。
- 心跳飞行棋有 4 位以上角色时，搭档条可以手指横滑、鼠标拖动、滚轮横向浏览，并能选到第 4 位之后的角色。
- 内容中心默认展示系统题，系统题总数应为 **128**；L1-L4 每档各 16 真心话 + 16 大冒险。
- 掷骰动画约半秒后必须停止；保存稍慢时可以显示“正在结算这一掷”，但骰子不能继续无限旋转。
- 总测试定义预期 **67 files / 598 tests**。
- `vue-tsc -b`、Vite build、`release:source-check` 通过。
