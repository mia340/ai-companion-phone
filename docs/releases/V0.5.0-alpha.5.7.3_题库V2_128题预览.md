# 心跳飞行棋 · 题库 V2（128 题）

> V0.5.0-alpha.5.7.3 / Couple Board V1.3.0

结构：4 档 ×（16 真心话 + 16 大冒险）= 128 题。系统仍保留 18+ 门禁、未成年硬阻断、换题与跳过。

## L1 日常甜

### 真心话

1. **[日常 · 聊天 + 面对面]** 最近最想和 {partner} 一起吃什么？别想高级餐厅，就说现在真想吃的。
2. **[回忆 · 聊天 + 面对面]** 你们最近哪一个很普通的小瞬间，回想起来还会觉得挺甜？
3. **[小闹 · 聊天 + 面对面]** {partner} 哪个小习惯最容易让你想笑，又舍不得吐槽？
4. **[回忆 · 聊天 + 面对面]** 如果把你们一次散步、吃饭或闲聊重来一遍，你会选哪次？
5. **[暧昧 · 聊天 + 面对面]** 你最喜欢 {partner} 怎么叫你？本名、昵称，还是某个只有你们懂的称呼？
6. **[日常 · 聊天 + 面对面]** 如果明天完全没安排，你最想和 {partner} 怎么懒一天？
7. **[小闹 · 聊天 + 面对面]** 你觉得 {partner} 什么时候最像小朋友？
8. **[日常 · 聊天 + 面对面]** 最近有没有什么没什么用、但很想和 {partner} 一起买的小东西？
9. **[回忆 · 聊天 + 面对面]** 最近一次发生什么事时，你第一反应是“这个得跟 {partner} 说”？
10. **[小闹 · 聊天 + 面对面]** 你们两个谁更会撒娇？举个最近的例子。
11. **[日常 · 聊天 + 面对面]** {partner} 哪个表情、语气词或表情包，你一看就知道 TA 在想什么？
12. **[日常 · 聊天 + 面对面]** 你最想和 {partner} 固定下来一个什么睡前小习惯？
13. **[小闹 · 聊天 + 面对面]** 如果现在只能点一份外卖一起吃，你会点什么？
14. **[暧昧 · 聊天 + 面对面]** 如果现在马上见到 {partner}，你第一件想做的事是什么？
15. **[日常 · 聊天 + 面对面]** 你最吃 {partner} 哪一种哄人方式？
16. **[回忆 · 聊天 + 面对面]** 有哪件小事你希望 {partner} 一直记得，因为你会觉得很甜？

### 大冒险

1. **[小闹 · 聊天 + 面对面]** 用三个词形容 {partner}，不许想超过五秒。
2. **[暧昧 · 聊天 + 面对面]** 给 {partner} 起一个今晚限定的昵称，接下来一回合都这么叫。
3. **[日常 · 仅聊天]** 发一个最能代表你现在心情的表情包或 emoji，不准解释。
4. **[小闹 · 仅面对面]** 和 {partner} 击个掌，然后谁都别先把手收回，撑五秒。
5. **[回忆 · 聊天 + 面对面]** 说一个只有你们俩听得懂的小梗。
6. **[日常 · 聊天 + 面对面]** 让 {partner} 选“奶茶 / 夜宵 / 散步”，你立刻说出一个想一起去的地方。
7. **[暧昧 · 仅聊天]** 发一条十个字以内、明显是在想对方的消息。
8. **[小闹 · 聊天 + 面对面]** 模仿一次 {partner} 最常用的语气或口头禅。
9. **[日常 · 聊天 + 面对面]** 给 {partner} 安排一个“今天不用动脑”的小福利。
10. **[暧昧 · 仅面对面]** 如果你们在一起，靠一下 {partner} 的肩，待五秒。
11. **[回忆 · 聊天 + 面对面]** 各说一件最近让你觉得“还好有你”的小事。
12. **[小闹 · 聊天 + 面对面]** 石头剪刀布一局，输的人要夸赢的人一句。
13. **[暧昧 · 聊天 + 面对面]** 补一句：“我其实最喜欢你____的时候。”
14. **[日常 · 仅聊天]** 给 {partner} 发一条你平时真的会发的“到家告诉我”。
15. **[小闹 · 聊天 + 面对面]** 让 {partner} 从 1 到 3 选数字，你就说同样数量个 TA 的可爱点。
16. **[日常 · 聊天 + 面对面]** 一起选一首今晚适合你们的歌，说出歌名就算完成。

## L2 暧昧

2. **[心动 · 聊天 + 面对面]** 你觉得 {partner} 哪种穿搭最戳你？
3. **[吃醋 · 聊天 + 面对面]** 你最容易在哪种小事上吃 {partner} 的醋？
4. **[暧昧 · 聊天 + 面对面]** 你更喜欢 {partner} 主动找你，还是故意等你先忍不住？
5. **[日常 · 聊天 + 面对面]** 如果今晚能单独待两个小时，你最想怎么过？
6. **[暧昧 · 聊天 + 面对面]** 你最想听 {partner} 在什么时候突然说一句“想你了”？
7. **[心动 · 聊天 + 面对面]** 你觉得 {partner} 最好看的地方是哪儿？只能选一个。
8. **[小闹 · 聊天 + 面对面]** 你有没有故意晚回过 {partner} 消息，想看看 TA 会不会来找你？
9. **[吃醋 · 聊天 + 面对面]** 如果有人当着你的面夸 {partner} 很有魅力，你第一反应是什么？
10. **[暧昧 · 聊天 + 面对面]** 你更喜欢被叫“宝贝”、名字，还是别的？说一个你真的会心动的。
11. **[心动 · 聊天 + 面对面]** 如果可以偷亲 {partner} 一下，你第一反应会选额头、脸还是嘴？

### 大冒险

1. **[暧昧 · 聊天 + 面对面]** 对 {partner} 说一句明显在撩 TA 的话，不许用“喜欢你”三个字。
2. **[暧昧 · 仅聊天]** 发一句“你再这样我就____了”，空格自己填。
3. **[心动 · 仅面对面]** 和 {partner} 对视十秒，谁先笑谁输。
4. **[吃醋 · 聊天 + 面对面]** 说一句带点吃醋、但听起来还很可爱的实话。
5. **[心动 · 聊天 + 面对面]** 夸 {partner} 一个外貌细节，要具体，不能只说“好看”。
6. **[暧昧 · 仅聊天]** 发一条像是随口问、其实很想见 TA 的消息。
7. **[亲密 · 仅面对面]** 愿意的话，抱 {partner} 十秒，中间不说话。
8. **[小闹 · 聊天 + 面对面]** 让 {partner} 选“乖一点 / 坏一点 / 黏一点”，你用那个语气说一句话。
9. **[暧昧 · 聊天 + 面对面]** 用“我承认，我刚刚有点……”开头，说一句关于 {partner} 的心动。
10. **[暧昧 · 仅聊天]** 给 {partner} 发一句“今晚给你一个特权：____”。
11. **[亲密 · 仅面对面]** 让 {partner} 在“牵手 / 靠肩 / 抱一下”里选一个，做十秒。
12. **[暧昧 · 聊天 + 面对面]** 把普通的“你在干嘛”改成一句一看就知道你在撩人的问法。
13. **[心动 · 聊天 + 面对面]** 盯着 {partner} 的眼睛或头像，说一句你平时会害羞不敢说的话。
14. **[小闹 · 聊天 + 面对面]** 让 {partner} 给你取一个昵称，下一回合你只能应这个昵称。
15. **[吃醋 · 聊天 + 面对面]** 说一句：“我会吃醋的点其实是____。”
16. **[暧昧 · 聊天 + 面对面]** 直接告诉 {partner} 一个你希望 TA 更主动的小瞬间。

## L3 亲密

### 真心话

1. **[亲密 · 聊天 + 面对面]** 你最喜欢 {partner} 抱你的哪种方式：正面抱、从背后抱，还是把你搂过去？
2. **[心动 · 聊天 + 面对面]** 如果要选一个最喜欢被 {partner} 亲的地方，你会选额头、脸、嘴还是颈侧？
3. **[亲密 · 聊天 + 面对面]** 你更喜欢短短亲一下，还是慢一点、久一点的吻？
4. **[心动 · 聊天 + 面对面]** {partner} 靠得很近的时候，什么最容易让你心跳加快：眼神、声音、味道还是动作？
5. **[日常 · 聊天 + 面对面]** 如果今晚一起睡，你更想抱着睡、牵手睡，还是各睡各的但靠很近？
6. **[亲密 · 聊天 + 面对面]** 你最喜欢 {partner} 怎么碰你：摸头、牵手、搂腰、抱紧，还是别的？
7. **[回忆 · 聊天 + 面对面]** 有没有哪次亲吻、拥抱或靠得很近的瞬间，你偶尔还会想起来？
8. **[暧昧 · 聊天 + 面对面]** 如果 {partner} 在你耳边说一句话，你最想听什么？
9. **[心动 · 聊天 + 面对面]** 你觉得自己身上哪个地方最希望 {partner} 觉得好看？
10. **[亲密 · 聊天 + 面对面]** 你最喜欢什么时候和 {partner} 黏在一起：刚见面、要分别、睡前，还是半夜？
11. **[暧昧 · 聊天 + 面对面]** 如果 {partner} 把你拉近一点，你更可能装镇定，还是直接顺势靠过去？
12. **[小闹 · 聊天 + 面对面]** 你觉得你们两个谁亲人的时候更容易害羞？
13. **[亲密 · 聊天 + 面对面]** 你最喜欢被 {partner} 从哪里抱住：肩、腰，还是整个人圈住？
14. **[心动 · 聊天 + 面对面]** 哪种“很近但还没亲上”的瞬间最撩你？
15. **[暧昧 · 聊天 + 面对面]** 如果今晚只能选一种亲密感，你要拥抱、接吻、贴着聊天，还是一起睡到自然醒？
16. **[亲密 · 聊天 + 面对面]** 你最喜欢 {partner} 在亲密的时候叫你什么？

### 大冒险

1. **[亲密 · 仅面对面]** 愿意的话，和 {partner} 抱十秒，这次抱紧一点。
2. **[心动 · 仅面对面]** 让 {partner} 选额头、脸或嘴，亲一下。
3. **[暧昧 · 仅聊天]** 发一句：“你现在要是在我旁边，我大概会先____。”
4. **[亲密 · 仅面对面]** 坐近一点，让你们的肩或腿轻轻碰到，保持十秒。
5. **[暧昧 · 聊天 + 面对面]** 在 {partner} 耳边或语音里说一句很近的悄悄话。
6. **[心动 · 仅面对面]** 如果都愿意，和 {partner} 接一个至少五秒的吻。
7. **[暧昧 · 聊天 + 面对面]** 让 {partner} 选“温柔 / 霸道一点 / 黏人”，你用那个风格说一句想靠近 TA 的话。
8. **[亲密 · 仅面对面]** 从背后抱一下 {partner}，或者让 TA 从背后抱你。
9. **[心动 · 聊天 + 面对面]** 直接告诉 {partner}：“你刚刚最让我心动的是____。”
10. **[暧昧 · 仅聊天]** 发一句不带 emoji 的暧昧消息，让 {partner} 一眼就看懂。
11. **[亲密 · 仅面对面]** 牵住 {partner} 的手，把 TA 拉近一点，再松开。
12. **[小闹 · 聊天 + 面对面]** 让 {partner} 选“亲一下 / 抱一下 / 说情话”，你完成一个。
13. **[暧昧 · 聊天 + 面对面]** 说一句：“你别这样看我，不然我会____。”

16. **[暧昧 · 聊天 + 面对面]** 用一句话把“今晚别离我太远”说得更撩一点。

## L4 成人 18+

### 真心话

1. **[成人 · 聊天 + 面对面]** 如果今晚真的想做爱，你更希望谁先开口？会怎么开口？
2. **[暧昧 · 聊天 + 面对面]** 你更喜欢慢慢撩到有感觉，还是直接告诉对方“我现在想要你”？
3. **[亲密 · 聊天 + 面对面]** 亲密的时候，你更喜欢被抱紧、被亲、被夸，还是被逗到受不了？
4. **[成人 · 聊天 + 面对面]** 你觉得前戏重要吗？你最在意的是接吻、触碰、说话还是气氛？
5. **[心动 · 聊天 + 面对面]** 你最喜欢 {partner} 亲你哪里？可以直接说。
6. **[成人 · 聊天 + 面对面]** 做爱前，你最想听 {partner} 对你说什么？
7. **[亲密 · 聊天 + 面对面]** 结束以后，你最想要哪一种：抱着、聊天、洗澡、吃东西，还是直接睡？
8. **[心动 · 聊天 + 面对面]** 你更喜欢灯亮一点、暗一点，还是关灯？为什么？
9. **[成人 · 聊天 + 面对面]** 你在床上更喜欢自己主动，还是被 {partner} 带着走？
10. **[成人 · 聊天 + 面对面]** 有没有一个你一直有点想试、但还没认真聊过的成人情趣？
11. **[暧昧 · 聊天 + 面对面]** 你觉得自己最容易在哪个瞬间被 {partner} 撩出感觉？
12. **[成人 · 聊天 + 面对面]** 你更喜欢亲密前先洗澡换衣服慢慢进入状态，还是想到就直接开始？
13. **[心动 · 聊天 + 面对面]** 如果只能选一个，你更在意接吻合拍、身体贴得舒服，还是聊天够大胆？
14. **[成人 · 聊天 + 面对面]** 你觉得理想的亲密频率更像“看感觉”、固定几次，还是想要就说？
15. **[暧昧 · 聊天 + 面对面]** 有没有一句成人情侣之间的话，只要 {partner} 说出来你就会很有感觉？
16. **[亲密 · 聊天 + 面对面]** 成人亲密里，你最不想省掉的一件事是什么：确认、避孕、安全感，还是结束后的照顾？

### 大冒险

1. **[暧昧 · 聊天 + 面对面]** 看着 {partner}，说一句：“我今天其实有点想要你。”
2. **[亲密 · 仅面对面]** 如果现在方便也都愿意，和 {partner} 接一个十秒的吻。
3. **[成人 · 仅聊天]** 发一句成年人一看就懂的暧昧消息，不准用 emoji 糊弄过去。
4. **[心动 · 聊天 + 面对面]** 直接告诉 {partner}：今晚你最想被怎么亲。
5. **[亲密 · 仅面对面]** 让 {partner} 选“抱紧一点 / 搂腰 / 亲一下”，完成一个。
6. **[成人 · 聊天 + 面对面]** 说一句：“今晚如果继续，我希望你____。”空格自己填。
7. **[成人 · 聊天 + 面对面]** 用 1 到 10 给你现在对 {partner} 的欲望值打分，再说一句原因。
8. **[暧昧 · 聊天 + 面对面]** 让 {partner} 选“温柔一点 / 直接一点 / 坏一点”，你用那个风格撩 TA 一句。
9. **[成人 · 仅面对面]** 愿意的话，贴近 {partner} 耳边说一句今晚最想做的事，不用说给别人听。
10. **[成人 · 仅聊天]** 发一句：“你要是在我旁边，我可能不会只想抱你。”
11. **[心动 · 仅面对面]** 选额头、嘴、颈侧三个位置中的一个，亲 {partner} 一下。
12. **[成人 · 聊天 + 面对面]** 各自说一个“今晚可以更大胆一点”的点，再说一个绝对不想做的点。
13. **[亲密 · 聊天 + 面对面]** 告诉 {partner} 你更喜欢 TA 在亲密时夸你、哄你、逗你，还是直接一点。
14. **[心动 · 仅面对面]** 关掉手机一分钟，靠近一点，只看着对方，不说话。
15. **[成人 · 聊天 + 面对面]** 说一句只会对成年伴侣说的情话，越直白越好，但别替对方做决定。
16. **[亲密 · 聊天 + 面对面]** 用一句最简单的话确认今晚的状态：“想继续 / 想慢一点 / 今天只想抱抱”，选一个。
