# V0.5.0-alpha.5.2.0 部署与更新

本版本是 **ChatRoom Generation Runtime 拆分第一阶段**。不升级 IndexedDB、Backup Schema 或 Launcher Schema，不需要清站点数据。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  44 passed (44)
Tests       373 passed (373)
```

随后 `vue-tsc -b && vite build` 与 `release:source-check` 必须成功。

## 行为兼容

- 流式回复仍只来自真实 Provider。
- 用户主动停止时，已经显示的真实 AI 文本继续保留并标记 cancelled。
- Provider/Token 错误时不使用本地角色内容续写。
- 角色、聊天、记忆、世界书、Persona、资源绑定、朋友圈和桌面布局数据全部保留。
