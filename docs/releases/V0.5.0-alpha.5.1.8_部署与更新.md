# V0.5.0-alpha.5.1.8 部署与更新

本版继续使用固定门禁：**解压 → 第一次 verify → 检查 Git → 同步 → 第二次 verify → commit → push**。

不要删除线上旧站点；不要清除浏览器站点数据、IndexedDB 或 LocalStorage。

## 1. 下载文件

把：

```text
ai-companion-phone-v0.5.0-alpha.5.1.8-windows-safe.zip
```

放到：

```text
D:\ai\
```

## 2. PowerShell 一次执行

```powershell
cd D:\ai

$zip  = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.8-windows-safe.zip"
$new  = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.8"
$repo = "D:\ai\ai-companion-phone-git-clean"

if (-not (Test-Path $zip)) {
    throw "找不到 ZIP：$zip"
}

if (Test-Path $new) {
    Remove-Item $new -Recurse -Force
}

Expand-Archive -Path $zip -DestinationPath $new -Force

if (-not (Test-Path "$new\package.json")) {
    throw "解压异常：缺少 package.json"
}
if (-not (Test-Path "$new\package-lock.json")) {
    throw "解压异常：缺少 package-lock.json"
}

# 第一次完整验证
cd $new
npm ci
if ($LASTEXITCODE -ne 0) { throw "npm ci 失败，停止部署" }

npm run verify
if ($LASTEXITCODE -ne 0) { throw "第一次 npm run verify 失败，停止部署" }

# Git 仓库必须没有未提交工作区修改
cd $repo
$dirty = git status --porcelain
if ($dirty) {
    git status
    throw "Git 仓库存在未提交修改，停止，避免覆盖"
}

git status
git log -3 --oneline

# 同步源码；保留 Git 元数据，不复制依赖和 dist
robocopy $new $repo /MIR /XD ".git" "node_modules" "dist"
$robocopyCode = $LASTEXITCODE
if ($robocopyCode -ge 8) {
    throw "robocopy 复制失败，错误码：$robocopyCode"
}

cd $repo
git status

# 第二次完整验证
npm ci
if ($LASTEXITCODE -ne 0) { throw "Git 仓库 npm ci 失败，停止部署" }

npm run verify
if ($LASTEXITCODE -ne 0) { throw "第二次 npm run verify 失败，停止部署" }

# 提交 / 推送
git add -A
git status

git commit -m "release: v0.5.0-alpha.5.1.8"
if ($LASTEXITCODE -ne 0) { throw "git commit 失败，停止" }

git push origin main
if ($LASTEXITCODE -ne 0) {
    throw "git push 失败；代码已经安全提交在本地，不要重新复制或重新 commit"
}

Write-Host ""
Write-Host "========================================"
Write-Host "alpha.5.1.8 已推送"
Write-Host "接下来等待 GitHub Actions 绿色成功"
Write-Host "========================================"
```

## 3. 验收

两轮 `npm run verify` 必须同时满足：

```text
Vitest passed
vue-tsc passed
vite build passed
```

专项 UI 验收：

1. 桌面左下角不再出现竖向白线；
2. 桌面左右滑动可切换 App 页；
3. 长按 App 后可拖拽排序；
4. App 可拖进 / 拖出 Dock；
5. Dock 已满时拖到已有 Dock App 上可交换；
6. 拖到左右边缘停留后可跨页；
7. 音乐、海龟汤、知间等原入口仍可正常打开；
8. 升级后旧角色、聊天、记忆、世界书、朋友圈数据仍在。

专项 Runtime 验收：

- Character Card 标准导入回归通过；
- 新安全边界单测通过；
- SullyOS-shaped WorldBook adapter 单测通过；
- Memory Retrieval V2 单测通过。
