# V0.5.0-alpha.4.2 部署与更新

当前交付：**V0.5.0-alpha.4.2 · Community Chat Compatibility**。本轮不升级数据库：IndexedDB **V16**，Backup **V11**。

## 1. 推荐：完整平铺包独立验收

将完整 ZIP 解压到：

```text
D:\ai\ai-companion-phone-v0.5.0-alpha.4.2
```

PowerShell：

```powershell
cd "D:\ai\ai-companion-phone-v0.5.0-alpha.4.2"
Test-Path .\package.json
npm install
npm test
npm run build
npm run dev
```

`Test-Path` 应返回 `True`。源码静态定义为 **30 个测试文件 / 272 个用例**。只有 `npm test` 与 `npm run build` 都通过后，才建议同步到 Git 工作区。

## 2. 本轮重点验收

### 苏玉尘 / WorldBook HTML 样本

1. 导入或打开苏玉尘角色卡。
2. 新建聊天 / 重新选择开场：`first_mes` 应直接进入作者的粉色状态栏 HTML，而不是第一条纯文本、第二条才突然变卡片。
3. 状态栏各行应正常换行；页面中不应出现字面量 `<br>` 或 `&lt;br&gt;`。
4. 发一条消息，后续 AI 回复应继续使用同一作者 UI。
5. 作者固定 `260px` 卡片不能横向撑破手机消息区域。
6. 作者 UI 自带背景 / border / `<style>` 时，不应再出现额外一层白色 Rich Bubble。
7. 已有 alpha.4.1 老会话：重新打开聊天时，旧的 `isGreetingSeed` 应能自动升级为作者 UI，不要求删聊天重建。

### 兼容矩阵

- 普通纯文本卡：保持普通聊天气泡。
- WorldBook HTML 卡：作者 UI 优先。
- Regex HTML 卡：富文本 Regex 优先。
- 作者直接 HTML：安全渲染作者 HTML。
- 玩家主动选择“纯聊天气泡 / 剧情气泡”：以玩家覆盖为准。

### 旧功能回归

- 聊天列表左滑删除。
- Character Shared Memory 不因删除某个聊天被误删。
- 首页长按进入“桌面与外观”。
- 主屏“记忆”进入 Memory Center。

## 3. 增量覆盖

如果你已经有干净的 `V0.5.0-alpha.4.1` 测试目录，可以把 overlay ZIP 解压到项目根目录并选择覆盖同名文件，然后重新执行：

```powershell
npm test
npm run build
```

不要把 overlay 解压到 `src` 子目录；它的目录结构已经从项目根开始。

## 4. 通过后同步 Git 工作区

假设测试目录与 Git 工作区都在 `D:\ai`：

```powershell
cd "D:\ai"
robocopy ".\ai-companion-phone-v0.5.0-alpha.4.2" ".\ai-companion-phone-git-clean" /E /XD .git node_modules dist /XF "*.tsbuildinfo" /R:2 /W:1

cd ".\ai-companion-phone-git-clean"
npm install
npm test
npm run build
git status
```

确认测试与 Build 都绿以后：

```powershell
git add -A
git commit -m "fix: standardize community chat UI compatibility v0.5.0-alpha.4.2"
git push origin main
```

## 5. 当前验证说明

当前容器已完成改动文件 TypeScript / Vue script 语法检查，并使用用户提供的苏玉尘 JSON 直接跑过本地 Community UI Compiler：`html-contract` 识别成功、作者模板填充成功、`&lt;br&gt;` 不再出现。

但容器里的 `node_modules` 不完整，`vitest` 不存在，因此本交付 **没有宣称容器内完整 Vitest / vue-tsc / Vite Build 已通过**。最终以 Windows 上的 `npm test` 和 `npm run build` 为准。
