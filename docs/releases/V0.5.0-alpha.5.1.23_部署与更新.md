# V0.5.0-alpha.5.1.23 部署与更新

部署包：`D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.23-windows-safe.zip`

本版本是 alpha.5.1.22 的发布门禁热修版：修复 `HomeScreen.vue` 未使用函数导致的 TypeScript TS6133。

部署要求：

1. ZIP 解压后执行 `npm ci` 与 `npm run verify`。
2. Git 仓库必须保持 clean。
3. `robocopy /MIR` 同步时排除 `.git`、`node_modules`、`dist`。
4. Git 仓库再次执行 `npm ci` 与 `npm run verify`。
5. 两轮 verify 全部通过后才允许 commit / push。
