# V0.5.0-alpha.4.5 Release Manifest

## 主题

叙事人称连续性 + 社区命名式 User Profile 兼容。

## 主要变更

- 默认旁白人称锁：无显式第三人称规则时，当前用户使用第二人称“你”。
- 资料中的“她/他/TA/女生”等不再视为人称指令。
- 默认 Persona UI 名“我/用户/User”等不直接替换 `{{user}}` 宏。
- Persona Prompt 明确区分 UI 名与世界内姓名。
- Lorebook Persona 支持 `{{user}}某某设定`、`<user_profile>`、`{{user}}固定对应某姓名`。
- 已导入旧角色可从绑定 Lorebook 恢复 Persona 预览。
- Prompt Debug 增加“叙事人称锁”。

## 数据版本

- IndexedDB: V16
- Backup: V11
- 无迁移 / 无清库。

## 验证状态

- TypeScript 语法级检查：通过（修改 TS + CharacterCardEditor script）。
- 真实卡结构独立探针：命名式 `<user_profile>` 识别通过，普通时间线条目低于 Persona 阈值。
- 完整发布门禁目标：31 test files / 280 tests + Vite build。
- 当前容器 npm 离线缓存缺少依赖 tarball，完整 `npm run verify` 需在 Windows/CI 完成。
