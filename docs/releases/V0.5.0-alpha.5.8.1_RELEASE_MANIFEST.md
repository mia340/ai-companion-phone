# V0.5.0-alpha.5.8.1 Release Manifest

## Scope

心跳飞行棋 V2.1 面对面互动修正。

## Runtime changes

- Challenge Bottom Sheet 支持垂直拖拽、三档停靠、“看地图 / 展开·收起”，并保证 topbar 不被遮挡。
- 新开、续局、再来一局统一按现实面对面模式运行；不推断房间、酒店等具体真实地点。
- 花店、公园、电影院、床边等地图节点仅为 Board Stop，不可作为现实环境或长期 Memory 事实。
- 题目严格归本轮掷骰者；另一方只在题后自然回应，不再强制共同回答/共同完成。
- 对话气泡不再重复显示姓名。
- V2.0 Character Context、Role Continuity Audit、Interaction Ledger、Memory Bridge、角色自动掷骰和双视觉地图继续保留。
