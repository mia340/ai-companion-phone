# V0.5.0-alpha.5.2.3 部署与更新

本版本是 **Generation Runtime 第四阶段（Prompt Debug + Final Persistence + Lifecycle Bookkeeping）**。继续缩小 `ChatRoom.vue`，不升级 IndexedDB、Backup Schema 或 Launcher Schema，不需要清站点数据。

## 本轮重点

- Prompt Debug Trace 的创建、完成诊断和 Provider HTTP error patch 下沉到 `promptDebugRuntime.ts`。
- alternative / rich / canonical-display / streaming / actions 五条最终持久化路径统一下沉到 `assistantReplyPersistenceRuntime.ts`。
- 成功、手动停止、非手动取消、Token 上限和普通 Provider 错误的状态收口到 `generationLifecycleRuntime.ts`。
- 自动摘要刷新也进入 Lifecycle Runtime；View 只接收 state/UI hooks。
- Provider 失败继续真实上抛，不生成本地角色回复。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  52 passed (52)
Tests       440 passed (440)
```

随后 `vue-tsc -b && vite build` 与 `release:source-check` 必须成功。
