# V0.5.0-alpha.5.1.6 · 知间 UI 收敛与空间设置

## 用户可见变化

- 「知间」四个主标签统一为：**知间 / 通讯录 / 发现 / 我**。
- 四个主标签页左上角都提供返回箭头，统一返回空间桌面；二级页继续按上一层返回，直接打开无历史记录时回到空间桌面。
- 知间聊天页增加右上角“＋”入口用于新建角色，搜索框改为“搜索聊天记录”。
- 通讯录只保留“新建角色 + 联系人列表”，搜索提示改为“搜索联系人”。
- 发现页只保留朋友圈，不再展示音乐、海龟汤、日记、扫一扫、看一看、搜一搜等暂不做入口。
- 「我」页收敛为：个人资料、空间设置、钱包、设置；朋友圈不再在「我」页重复出现。
- 新增「空间设置」：好友自主动态、动态可见范围、谁可以看、不让他看、黑名单。
- 空间桌面只保留六个核心入口：**知间 / 我的资料 / 记忆 / 世界 / 数据备份 / 设置**，移除重复 Dock 和音乐/日记/海龟汤桌面入口。
- 重做「知间」App 图标，不再使用双聊天气泡造型。

## Runtime 变化

- 空间设置复用 `appCustomizations` 的非索引字段持久化，不升级 IndexedDB。
- 动态“仅自己”时，不再为用户新动态排队角色自动评论/点赞；执行旧队列前会再次校验。
- 黑名单角色不会进入 Social Runtime 候选池、不会自主发朋友圈；旧队列执行前也会取消。
- 单角色“谁可以看 / 不让他看”继续复用 `CharacterSocialProfile.canViewMoments`，与 Social Runtime V2 现有权限一致。

## 数据兼容

- App：`0.5.0-alpha.5.1.6`
- IndexedDB：**V18**（不变）
- Backup：**V12**（不变；`appCustomizations` 已在备份范围内，因此空间设置会随备份保存）
- 不删除角色卡、聊天、朋友圈、记忆、世界书或历史自定义图标数据。
