# V0.5.0-alpha.5.1.3 发布说明

- API 响应诊断：HTTP 状态、finish_reason、结构化拒绝标记与保守文本拒绝提示；不将文本拒绝误判成平台归因。
- 调试信息只收集诊断布尔值和状态，不存 API Key、请求头、原始返回 JSON 或错误正文。
- 保持成年用户之间的虚构情感与恋爱互动，不添加应用级“所有浪漫剧情禁止”规则；服务商自身策略与适用法律无法由客户端关闭。
- Social Runtime V2 和朋友圈封面保留，IndexedDB V18、Backup V12 不变。
- 本版本需要在 Windows 运行 `npm run verify`，未在当前环境跑通完整依赖构建。
