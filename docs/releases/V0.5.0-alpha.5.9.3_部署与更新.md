# V0.5.0-alpha.5.9.3 部署与更新

本版为 Companion Avatar / 穿搭 V1.3 的视觉与风格库重构。

使用发布目录中的 Windows Safe ZIP 与 PS5.1-safe 脚本部署。

本版不升级 IndexedDB、Backup 或 Launcher HomeLayout revision。旧 V1 / V1.1 / V1.2 穿搭数据会在运行时兼容迁移；新增的随身物、袜子、纹理、强调色以及更多套装继续保存在现有 `appCustomizations.wardrobeState` 非索引字段中。

最终门禁：

```text
npm test
vue-tsc -b
vite build
release-safety
```
