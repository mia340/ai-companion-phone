# V0.5.0-alpha.5.1.6 更新与部署

## 推荐更新方式

请解压到一个**全新目录**，不要把 `node_modules` 从旧版本复制过来。

```powershell
npm ci
npm run verify
```

只有 `npm run verify` 全部通过后，再按项目原有 GitHub Pages / 静态站点流程部署。

## 数据说明

本次 **IndexedDB 仍为 V18，Backup 仍为 V12**，没有数据库迁移。请不要清空站点数据；旧角色卡、聊天记录、朋友圈、记忆、世界书、Persona、自定义图标会继续保留。

空间设置使用已有 `appCustomizations` 表保存，因此会自然进入现有 Backup V12。

## 建议人工验收

1. 空间桌面只显示：知间、我的资料、记忆、世界、数据备份、设置；没有额外 Dock。
2. 打开知间后底部为：知间、通讯录、发现、我；四页左上角返回箭头可回到空间桌面。
3. 发现页只有朋友圈入口。
4. 我页只有个人资料、空间设置、钱包、设置。
5. 空间设置可以切换自主动态、可见范围和单角色可见权限；黑名单能正常加入/移除。
6. 把动态可见范围设成“仅自己”后，新发动态不会排队角色自动评论/点赞。
7. 加入黑名单的角色不会参与后续朋友圈自动互动，也不会自主发动态。
8. 聊天、角色卡、Community UI、WorldBook、Regex、Generation Runtime 行为不应发生回归。

## 当前交付环境说明

本次容器中的源码包未包含完整 `node_modules`；`npm test` 会因 `vitest` 缺失而无法在该容器完成。依赖安装尝试超时，因此正式发布仍必须在 Windows / CI 上执行 `npm run verify`，不要把“未能运行”误报成“测试失败”或“测试通过”。
