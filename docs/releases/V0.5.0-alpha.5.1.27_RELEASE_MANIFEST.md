# V0.5.0-alpha.5.1.27 Release Manifest

## Scope

WorldBook Engine direct-test hardening only. No IndexedDB schema, Backup schema, Launcher layout schema, chat runtime behavior, or character/memory data-model change.

- `src/services/lorebookService.test.ts`

  - keyword matching, case sensitivity and whole-word semantics;
  - regex matching and invalid-regex safety;
  - selective `and_any / and_all / not_any / not_all` semantics;
  - scan depth and recalled-message exclusion;
  - Character / Persona contextual matching switches;
  - multi-wave recursive activation plus `preventRecursion / excludeRecursion`;
  - sticky / cooldown / delay timed effects;
  - deterministic group-scoring winner selection;
  - probability boundary behavior;
  - per-lorebook token budget deferral;
  - At-Depth role/depth/order injection and named Outlet routing.
