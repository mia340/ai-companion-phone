# V0.5.0-alpha.5.7.0 Release Manifest

Release name: **Couple Board V1.2 / 心跳飞行棋 V1.2**

## Included

1. Dedicated Couple Content Center for custom prompts, system-prompt enable/disable, filters, editing and portable JSON import/export.
2. Editable custom event cards with heart deltas, position swap and extra-turn effects; the event deck is frozen into each active session.
3. Local Couple Board archive for the latest 24 completed games with deterministic statistics and Heartbeat Highlights.
4. Evidence V2: AI challenge generation may use verified Memory plus factual Shared Timeline evidence for the same character; promise/goal/story signals remain excluded.
5. Unified evidence IDs with strict allow-list validation; legacy `memoryEvidenceIds` remains only for real Memory IDs.
6. User-triggered final-result chat draft; no auto-send and no automatic Memory/Relationship writes.
7. Empty prompt/event pools safely pass the corresponding board cell instead of crashing.
8. More secondary routes are lazy-loaded to reduce initial bundle pressure.
9. Regression definitions: 67 test files / 597 declarations, including 46 direct Couple Board tests.

## Safety contract

- AI generation remains user-triggered only.
- Memory and Shared Timeline text are evidence data, never executable instructions.
- Unknown evidence IDs, wrong challenge types and evidence-free model results are rejected.
- Promise/goal/story signals are not treated as completed shared experiences.
- Generated questions and game archives never auto-write Memory, Shared Event or Relationship State.
- Challenge/result chat bridges create local drafts only.
- Existing L4 adult confirmation and known-minor block remain unchanged.

## Release gate

The package must pass twice (extracted source and clean Git repo):

```text
npm ci
npm run verify
```

Then pass Git preflight/staged safety checks and `git diff --cached --check`. Windows/CI output is authoritative.
