# V0.5.0-alpha.4.3 Release Manifest

## Identity

- App: AI Companion Phone
- Version: `0.5.0-alpha.4.3`
- IndexedDB: V16
- Backup: V11
- Theme: Threaded Moments + Embedded User Persona Import

## Scope

- Add comment-to-comment reply references and threaded reply UX in Moments.
- Let the directly replied character continue the comment thread with reply context.
- Change default `lively` interaction to 2–3 characters and `party` to 3–5 when enough candidates exist.
- Detect explicitly labeled user/controller persona blocks in Character Card `creator_notes` without injecting all creator notes into Prompt.
- Let already-imported cards recover the same preview in Character Card Editor and create/bind a character-scoped Persona in place.

## Data compatibility

- IndexedDB remains **V16**.
- Backup remains **V11**.
- `MomentComment.replyToCommentId` is optional and unindexed, so no Dexie schema migration is required.
- Existing comments remain valid because missing reply references are treated as top-level comments.

## Static verification

- Source definitions: **30 test files / 275 tests**.
- Changed TypeScript files and Vue `<script setup lang="ts">` blocks passed syntax-level TypeScript transpilation checks.
- Full dependency install was not possible offline in the delivery container; Windows must run `npm test` and `npm run build` before deployment.

## Required Windows acceptance

```powershell
npm install
npm test
npm run build
npm run dev
```

Functional acceptance must cover creator_notes Persona recognition/binding and threaded Moments replies with multiple characters.
