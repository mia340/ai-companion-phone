# V0.5.0-alpha.5.6.0 部署与更新

本版本开始心跳飞行棋 V1.1：加入自定义题库、真实共同回忆 AI 出题、情侣事件卡、Heartbeat Highlights 和更完整的骰子/棋子/任务卡动效。

数据层没有迁移：IndexedDB 仍为 V18、Backup 仍为 V12、Launcher Grid / HomeLayout revision 仍为 13。旧 V1 棋局缺少的新字段均为 optional，可继续解析。

## 功能冒烟

1. 进入「心跳飞行棋」，创建聊天模式 L2 自定义真心话，开局后能从题池抽到。
2. 落在挑战格时点击“用真实共同回忆重新出题”：有真实 evidence 时生成题；无证据时给出明确提示，不凭空生成。
3. 生成题显示 `OUR MEMORY`，完成后终局高光能出现真实回忆卡；原 Memory 内容不被修改。
4. 落在“事件”格后先处理事件卡才能继续掷骰子。
5. 中途退出再进入可恢复 pending challenge / pending event；5.5.x 老存档也能继续。
6. 聊天模式“带到知间”只写草稿，不自动发送。
7. L4 仍要求 18+ 显式确认；已知未成年角色仍被 Runtime 阻断。

## Windows 固定门禁

把源码 ZIP 解压到新的空目录，然后执行：

```powershell
npm ci
npm run verify
```

通过后再同步到 clean Git repo，第二次执行相同两条命令。两轮均通过后才能：

```powershell
npm run release:git-working
git add -A
npm run release:staged-check
git diff --cached --check
git commit -m "release: 0.5.0-alpha.5.6.0 couple board v1.1"
git push origin main
```

最终以部署机两轮 `npm run verify` 实际输出为准。
