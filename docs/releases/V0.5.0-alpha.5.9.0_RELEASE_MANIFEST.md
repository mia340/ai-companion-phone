## 本轮主要变化

- 新增独立「穿搭」App，可设计用户自己与每一个角色的 Q 版形象。
- 穿搭按男女两套版型提供不同发型 / 上装 / 下装，可保存多套 Outfit。
- 新增共享 `CompanionPixelAvatar` 与 `avatarWardrobeService`，为其他小游戏复用。
- 心跳飞行棋 V2.3 接入当前穿搭，小人不再是固定方块角色。
- 顶部人物 HUD 收窄、地图放大、地点说明改为小型悬浮卡，固定半屏互动继续保留。
- Launcher revision 14 会为旧布局一次性补入「穿搭」App，不增加 IndexedDB schema。
