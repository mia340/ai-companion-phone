# V0.5.0-alpha.4.4.1 部署与更新

本版是 alpha.4.4 的通用社区 Persona 兼容热修。IndexedDB V16、Backup V11 不变，不需要清数据或迁移。

## Windows 本地运行

将 `ai-companion-phone-v0.5.0-alpha.4.4.1-windows-safe.zip` 放到 `D:\ai`，PowerShell：

```powershell
cd "D:\ai"

if (Test-Path ".\ai-companion-phone-v0.5.0-alpha.4.4.1") {
    Remove-Item ".\ai-companion-phone-v0.5.0-alpha.4.4.1" -Recurse -Force
}

Expand-Archive `
  -LiteralPath ".\ai-companion-phone-v0.5.0-alpha.4.4.1-windows-safe.zip" `
  -DestinationPath ".\ai-companion-phone-v0.5.0-alpha.4.4.1" `
  -Force

cd ".\ai-companion-phone-v0.5.0-alpha.4.4.1"
Test-Path ".\package.json"
npm install
npm run verify
```

`Test-Path` 必须为 `True`。`npm run verify` 预期：

```text
Test Files  30 passed (30)
Tests       277 passed (277)
```

随后应自动完成 Build 并出现 `✓ built in ...`。

启动开发服务器：

```powershell
npm run dev
```

浏览器：`http://localhost:5173/ai-companion-phone/`

## Persona 专项验收

不要只测一张卡。建议至少覆盖：

1. 世界书 `user人设 / user设定 / user基本情况`；
2. creator_notes `[用户设定] / [我的设定] / 玩家人设 / 主控人设`；
3. `player_profile / user_profile` 对象字段；
4. 英文字段 `name / age / gender / height / occupation`；
5. `user_personal_room`、衣橱、座驾、手机等误判保护；
6. “user人设自拟 / 请填写用户设定”只有提示而无实际身份信息时不创建 Persona。

## GitHub Pages 部署

本地 `npm run verify` 全绿后同步正式 Git 工作区：

```powershell
cd "D:\ai"

robocopy `
  ".\ai-companion-phone-v0.5.0-alpha.4.4.1" `
  ".\ai-companion-phone-git-clean" `
  /E /XD .git node_modules dist `
  /XF "*.tsbuildinfo" /R:2 /W:1

cd ".\ai-companion-phone-git-clean"
npm install
npm run verify
git diff --check
git status
```

确认全部通过后：

```powershell
git add -A
git commit -m "fix: normalize community persona fields and remove local probe"
git push origin main
```

GitHub Actions 会重新执行测试、Build 并部署 `dist`。Vite base 仍为 `/ai-companion-phone/`。
