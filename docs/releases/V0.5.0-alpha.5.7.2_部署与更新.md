# V0.5.0-alpha.5.7.2 部署与更新

本版只处理心跳飞行棋阻断型可玩性问题，不升级数据库或 Backup。

重点验收：

1. 搭档卡片可直接点击切换，4 个以上角色可触摸横滑/滚轮/箭头浏览。
2. “继续”能恢复上一局，不出现 `structuredClone` / `DataCloneError`。
3. 连续掷骰子至少 15 次，骰子每次都停止并完成结算。
4. 开局保存失败时仍停留设置页，不出现半开局。

部署仍使用 Windows 双门禁：

```powershell
npm ci
npm run verify
```

Gate 1 通过后再同步 Git 仓库；Gate 2 再次通过后提交并 push。
