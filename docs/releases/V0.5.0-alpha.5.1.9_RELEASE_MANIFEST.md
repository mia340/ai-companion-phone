## 本轮目标

根据 alpha.5.1.8 真机截图继续收紧 Launcher：消除左侧竖白线、编辑态不再整体下沉、分页改为持久页面状态，并把音乐图标统一成用户指定的单音符样式。

## 主要变更

### Launcher Runtime V3

- `PhoneFrame` 新增 `lockScroll`，主屏不再继承普通页面的纵向滚动层；
- Home Page 固定为不可纵向滚动的手机桌面画布；
- 删除编辑态 226px 顶部让位，编辑菜单作为 overlay；
- 新增 `homePageKeys: HomeAppKey[][]` 持久分页；
- 旧 `homeAppKeys[]` 自动迁移，至少保留两页；
- 拖到目标页时显式保存 page index；
- 页面编辑器可新增、跳转、删除页面；
- 删除页面只合并 App 入口，不删除业务数据。

### 音乐图标

- AppIcon 的 Music glyph 从双音符改为单音符；
- 「一起听」Widget 直接复用同一 `AppIcon`；
- 桌面 / Dock / 设置预览 / Widget 不再出现两套音乐图标语言。

## 数据兼容

- IndexedDB 仍是 V18；
- Backup 仍是 V12；
- `homePageKeys` 写入现有 `appCustomizations` 非索引字段，不需要 Dexie schema migration；
- 不清除 IndexedDB / LocalStorage / 浏览器站点数据。
