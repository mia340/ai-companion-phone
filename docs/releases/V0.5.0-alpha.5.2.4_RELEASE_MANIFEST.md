# V0.5.0-alpha.5.2.4 Release Manifest

## Scope

TypeScript release hotfix for Generation Runtime phase 4. This release fixes the three compile-time regressions exposed by the first Windows `npm run verify` of alpha.5.2.3. Runtime behavior and all data schemas remain unchanged.

## Fixes

- `communityUiRepairRuntime.test.ts` now builds a structurally valid `UserPersona` fixture with `avatar` and `isDefault`; the stale `worldId` test-only field is removed.
- `CommunityUiCompiledCandidate` is now the canonical `RegexPipelineView` type instead of a narrowed duplicate shape. This preserves `rawText` and `traces` through Community UI repair and keeps the repaired candidate assignable to ChatRoom's Regex pipeline view.
- Removed the now-unused `renderRoleplayText` import from `ChatRoom.vue`.

## Test matrix

- Test files expected: 52
- Test declarations/cases expected: 440

## Compatibility

- IndexedDB: V18 (unchanged)
- Backup: V12 (unchanged)
- Launcher: Grid V13 / HomeLayout revision 12 (unchanged)
- Generation Runtime behavior: unchanged from alpha.5.2.3
- Provider failure policy: real Provider errors only; no local character reply fallback

## Release gate

Windows deployment must pass two complete `npm ci` + `npm run verify` gates. `vue-tsc -b` must pass before Vite build, then Release Safety source/Git/staged checks must all pass.
