# V0.5.0-alpha.5.1.1 · 朋友圈页面层级与背景封面

基于 alpha.5.1 的 UI 修复；Social Runtime V2、持久评论/角色互评、权限和通知数据库保持原有行为。

- 朋友圈新增顶部横幅封面，显示当前用户昵称与头像。可以本地选 JPG/PNG/WebP；处理压缩后最多 2 MB；可恢复默认封面。
- 新互动、朋友圈设置、每位好友的社交权限为真正的独立路由页面，随 PhoneFrame 内容区域滚动；不再统一从底部弹出。
- 通知点击后返回对应动态；通知页面打开后标记已读，首页角标同步更新。
- 封面按 worldId 保存到既有 appCustomizations，进入现有 Backup V12，无新增 store、无需重建数据库；IndexedDB 保持 V18。
- 不重写 Social Runtime 或 Persona 解析；不改变任何旧角色、消息、世界书、朋友圈及其评论。

## 发布门禁

`npm run verify` = `npm test && npm run build`。必须以 Windows 上的实际测试和构建输出为准；打包/静态语法检查不能替代 Vitest + vue-tsc + Vite。
