# V0.5.0-alpha.5.1.16 部署与更新

继续使用 **IndexedDB V18 / Backup V12**。不要清除浏览器站点数据。

固定门禁：**解压 → `npm ci` → `npm run verify` → 检查 Git 工作树 → robocopy → 第二次 `npm ci && npm run verify` → commit → push**。任一 verify 失败立即停止。

## 本版专项验收

1. 历史第二页如果确实没有任何 App / Widget / Folder，第二个分页圆点应自动消失；
2. 进入一个真正空白的稳定页后，当前页 DOM 自愈会回收该页；
3. 拖一个 App 到另一个 App 图标上，松手后形成文件夹；
4. 再拖第三个 App 到该文件夹，成员数量增加；
5. 点击文件夹可打开成员面板；编辑时可改名、把 App 移出；
6. 文件夹只剩一个 App 时自动解散；
7. 文件夹自身仍能在 4×6 Grid 中移动并参与 insert/reflow。
