# V0.5.0-alpha.5.3.1 部署与更新

本版本为 **「时光 / 共同回忆」V1.1**。不升级 IndexedDB、Backup 或 Launcher HomeLayout revision，不需要清站点数据。

## 新功能验收

- 时光页可以搜索标题、正文、角色和来源。
- 可以切换“最近 30 天 / 往年今天 / 最初记录”，并按月份分组展示。
- 聊天图片和音乐消息可以进入时光；图片可直接预览，所有媒体证据仍可跳回原消息。
- 带图片的朋友圈动态在时光里显示图片预览。
- AI 整理只针对当前筛选结果。
- 角色主动消息在没有更高优先级触发时，可以引用一条至少 7 天前的真实时光 evidence；隐藏证据不可被引用，且 Prompt 明确禁止补写旧事。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  56 passed (56)
Tests       469 passed (469)
```

随后 `vue-tsc -b && vite build` 与 Release Safety 必须全部成功。
