# V0.5.0-alpha.5.2.1 Release Manifest

## Scope

ChatRoom Generation Runtime extraction phase 2, expanded in one release. This release moves final assistant-output normalization/projection/persistence planning and action-message persistence orchestration out of `ChatRoom.vue` while preserving Provider, Regex, Community UI, memory/state and data-schema semantics.

## Runtime changes

- Added `src/runtime/generation/assistantReplyFinalizationRuntime.ts`.
  - Owns final assistant parse normalization, stable visible macros, display-only Regex reparse, manual presence override, native action projection, visible-output selection, role-card visibility, persistence-mode planning and Regex debug summarization.
- Added `src/runtime/generation/assistantActionPersistenceRuntime.ts`.
  - Owns action-to-message type mapping, pacing delays, latest user/assistant target resolution, recall/reaction side effects, placeholder replacement, reply-group metadata distribution, image placeholder persistence and per-action message persistence.
- `ChatRoom.vue` now delegates final reply shaping and final persistence strategy to Runtime instead of branching locally across raw/Regex/community/rich/streaming/action paths.
- Streaming final-message reuse now persists `regexApplied` metadata consistently with non-streaming paths.
- The View keeps only orchestration that still legitimately depends on live UI/provider/community-repair state.

## Regression coverage

Added 21 direct Runtime tests across two new test files:

- `assistantReplyFinalizationRuntime.test.ts` — 13 cases covering macros, card-UI suppression, display Regex reparse, canonical/display separation, manual presence override, native reshaping on/off, phone-text empty-output guards, rich/community ownership, persistence-mode precedence, role-card visibility and Regex debug summaries.
- `assistantActionPersistenceRuntime.test.ts` — 8 cases covering message-type mapping, pacing, target resolution, streaming-placeholder replacement, first-message metadata ownership, recall, reaction and image-placeholder storage.
