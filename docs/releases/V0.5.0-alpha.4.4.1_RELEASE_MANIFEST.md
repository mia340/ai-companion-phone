# V0.5.0-alpha.4.4.1 Release Manifest

## 目标

修复 alpha.4.4 在真实 Windows 验收中暴露的两个发布阻塞，同时继续坚持“社区卡通用兼容，不针对某一张卡写特判”。

## 修复内容

- 对结构化社区 Persona 字段做通用归一化：
  - `29岁` → `29`
  - `31 years old` → `31`
  - `172 cm` → `172cm`
  - `23岁(生日...)` / `23岁（生日...）` 继续可识别。
- `user_profile` / `player_profile` 等对象型 Persona 增加英文结构化字段信号：`name`、`age`、`gender`、`height`、`occupation`、`identity` 等。
- 保留中文 creator_notes / 世界书 / description / HTML 人物档案等既有兼容逻辑。
- 保留误判保护：`user_personal_room`、住所、衣橱、座驾、手机、NPC、只有“人设自拟/请填写”提示的内容不得创建 Persona。
- 删除开发期 `src/services/__communityCorpusProbe.test.ts`。该文件硬编码容器 `/mnt/data/community_cards`，不属于可发布测试，alpha.4.4 误打包后导致 Windows `ENOENT`。

## 社区语料独立运行

对用户提供的 49 份 JSON 使用发布版解析器做独立扫描：

- 32 份被识别并解析为角色卡；
- 17 份被正确识别为世界书或 Prompt 预设并拒绝从角色卡入口导入；
- 32 份角色卡中 17 份检测到独立用户 Persona；
- 中文结构化字段、英文结构化字段、同行 `[我的设定]...`、HTML Persona、`{{user}}` 模板和误判保护均在独立运行中验证。

## 数据兼容

- Backup：V11（不变）
- 无数据库迁移
