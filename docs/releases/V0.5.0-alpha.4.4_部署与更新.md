# V0.5.0-alpha.4.4 部署与更新

## 本地运行

```powershell
cd "D:\ai"
Expand-Archive `
  -LiteralPath ".\ai-companion-phone-v0.5.0-alpha.4.4-windows-safe.zip" `
  -DestinationPath ".\ai-companion-phone-v0.5.0-alpha.4.4" `
  -Force

cd ".\ai-companion-phone-v0.5.0-alpha.4.4"
Test-Path ".\package.json"
npm install
npm run verify
npm run dev
```

浏览器：`http://localhost:5173/ai-companion-phone/`

## 本轮专项验收

1. 导入不同社区角色卡，检查创建页是否能识别世界书 / creator_notes / 扩展字段里的用户 Persona。
2. 含“我的设定”“玩家人设”“主控人设”“user profile”等标签的卡不应依赖具体姓名。
3. `user_personal_room`、住所、衣橱、手机等不应被创建为 Persona。
4. 只有“user 人设自拟 / 请填写”而没有具体身份内容的卡不应生成伪 Persona。
5. 卡本身没有独立用户 Persona 时，仍应显示“未安全提取”，并使用当前聊天 Persona。

## GitHub Pages 部署

本地 `npm run verify` 全绿后再同步：

```powershell
cd "D:\ai"
robocopy `
  ".\ai-companion-phone-v0.5.0-alpha.4.4" `
  ".\ai-companion-phone-git-clean" `
  /E /XD .git node_modules dist `
  /XF "*.tsbuildinfo" /R:2 /W:1

cd ".\ai-companion-phone-git-clean"
npm install
npm run verify
git diff --check
git status

git add -A
git commit -m "feat: generalize community card persona detection"
git push origin main
```

GitHub Actions 成功后自动部署 `dist` 到 GitHub Pages；Vite base 仍为 `/ai-companion-phone/`。
