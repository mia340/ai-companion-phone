## 专项验收

1. 心跳飞行棋与情侣内容中心顶部显示 `V1.4.0`。
2. 系统题为 **160 道**；L1-L5 每档各 16 真心话 + 16 大冒险。
3. 开局强度新增 `L5 私房`，L4/L5 都显示 `18+`，都必须勾选成年人确认。
4. 明确年龄小于 18 岁的角色不能进入 L4 或 L5。
5. 内容中心可以筛选 L5，自定义题也可以创建 L5；L4/L5 自定义题都自动标记为 adult-only。
6. 面对面模式连续抽取大冒险时，各档都应出现明显更多身体互动题；聊天模式不会强塞现实动作。
7. 连续完成/换题时，近期题目 id / 主题防重复继续工作。
8. 角色选择、继续上一局、掷骰子主链继续回归，确认 5.7.2 的可玩性修复没有回退。
