# V0.5.0-alpha.5.9.5 部署与更新

本版重点不是继续堆穿搭插画，而是把“小手机里看到的东西”和“游戏真正运行的东西”统一起来，并清理普通手机聊天中不自然的 AI 测试界面。

部署后进入「穿搭」，顶部应显示 `WARDROBE · V1.5`。主预览和「套装」卡片会直接渲染 `CompanionPixelAvatar`，也就是飞行棋等小游戏使用的同一套实时小人。换上装、下装、颜色或配饰时，主预览应立即变化；不再出现静态大插画和右下角另一个小小 `GAME SPRITE` 的“双重形象”。

进入普通聊天后，助手消息下方不应出现 👍 / 👎 质量反馈按钮，也不应显示“参考了 X 条记忆”之类的内部调试面板。记忆召回仍在后台工作；如果启用「模型设置 → 向量语义记忆」，召回会混合 embedding 语义相似度、关键词、重要度与时间。embedding 接口失败时继续软降级，不阻断聊天。

「知间」会话列表的滑动删除仍保留，但红色只存在于右侧隐藏的删除操作层，不再作为整行底色，因此普通静止列表不应出现横贯页面的红色细线。

Memory 巩固仍是后台行为：累计一定消息后，可把较早的零散事实提炼为少量长期剧情记忆，并对长期未召回的低重要度记忆降权；不会在普通聊天里弹出“系统已巩固记忆”提示，也不会删除原始聊天消息。

数据库版本、Backup 版本和桌面布局 revision 都未升级；旧角色、聊天、Memory、穿搭和游戏记录继续兼容。
