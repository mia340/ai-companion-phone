## Social Runtime 专项验收

1. 至少准备 3 个角色，把朋友圈“回复热度”设为“🔥 热闹”。
2. 以自己身份发布一条朋友圈，发布后立刻离开朋友圈进入消息/设置页；等待 15～30 秒再回来，应能看到多个角色错峰评论。
3. 点某个角色的评论并回复，随后可以离开朋友圈；回到朋友圈后，被回复角色应继续回复你的那条评论。
4. 等待一会儿，评论区应有概率出现“角色 A 回复 角色 B”的互动；热度越高越明显。
5. 评论串不应无限生成；达到线程深度后自动停止。
6. 关闭/最小化导致页面被系统挂起时不会强行后台请求 API；重新打开 App 后，到期队列会继续执行。这是 Web/PWA 的可靠语义。
7. 删除动态后，该动态尚未执行的社交队列应一并清理。
