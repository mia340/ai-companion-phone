# V0.5.0-alpha.4.2.1 部署与更新

这是 `V0.5.0-alpha.4.2` 的 Windows Build 热修版。IndexedDB **V16**、Backup **V11** 均不变化。

## 1. 独立验收

建议解压到：

```text
D:\ai\ai-companion-phone-v0.5.0-alpha.4.2.1
```

PowerShell：

```powershell
cd "D:\ai\ai-companion-phone-v0.5.0-alpha.4.2.1"
Test-Path .\package.json
npm install
npm test
npm run build
npm run dev
```

`Test-Path` 应返回 `True`。当前测试基线为 **30 个测试文件 / 272 个用例**。

## 2. 本轮重点验证

`npm run build` 不应再出现：

```text
src/views/HomeScreen.vue:142:3 - error TS2322:
Type 'number' is not assignable to type 'Timeout'.
```

同时在浏览器中验证：

1. 主屏正常打开；
2. 主屏空白区域长按约 0.5 秒仍能进入“桌面与外观”；
3. 短按/滑动不会误触长按；
4. 聊天、记忆、朋友圈、音乐、海龟汤基础入口正常。

## 3. 构建产物

`npm run build` 成功后会生成：

```text
dist\
```

本项目 Vite 配置当前 `base` 为 `/ai-companion-phone/`，适合部署在 GitHub Pages 的同名仓库子路径。

## 4. 同步到 Git 工作区

假设正式 Git 工作区为：

```text
D:\ai\ai-companion-phone-git-clean
```

执行：

```powershell
cd "D:\ai"
robocopy ".\ai-companion-phone-v0.5.0-alpha.4.2.1" ".\ai-companion-phone-git-clean" /E /XD .git node_modules dist /XF "*.tsbuildinfo" /R:2 /W:1

cd ".\ai-companion-phone-git-clean"
npm install
npm test
npm run build
git diff --check
git status
```

全部通过后：

```powershell
git add -A
git commit -m "fix: browser long press timer build type"
git push origin main
```

## 5. GitHub Pages 部署

如果你的 GitHub Pages 已经配置为通过仓库现有工作流或构建流程发布，push 后按原流程发布即可。部署完成后重点检查站点路径是否仍为：

```text
/ai-companion-phone/
```

如果使用手工静态托管，则上传 `dist` 目录中的构建产物，并确保托管路径与 Vite `base` 匹配。
