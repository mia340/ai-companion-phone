# V0.5.0-alpha.5.1.9 部署与更新

固定流程：**解压 → 第一次 verify → 检查 Git → 同步 → 第二次 verify → commit → push**。

不要删除旧站点；不要清浏览器站点数据、IndexedDB 或 LocalStorage。

## PowerShell

```powershell
cd D:\ai

$zip  = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.9-windows-safe.zip"
$new  = "D:\ai\ai-companion-phone-v0.5.0-alpha.5.1.9"
$repo = "D:\ai\ai-companion-phone-git-clean"

if (-not (Test-Path $zip)) { throw "找不到 ZIP：$zip" }
if (Test-Path $new) { Remove-Item $new -Recurse -Force }
Expand-Archive -Path $zip -DestinationPath $new -Force

if (-not (Test-Path "$new\package.json")) { throw "解压异常：缺少 package.json" }
if (-not (Test-Path "$new\package-lock.json")) { throw "解压异常：缺少 package-lock.json" }

cd $new
npm ci
if ($LASTEXITCODE -ne 0) { throw "npm ci 失败，停止部署" }
npm run verify
if ($LASTEXITCODE -ne 0) { throw "第一次 npm run verify 失败，停止部署" }

cd $repo
$dirty = git status --porcelain
if ($dirty) {
    git status
    throw "Git 仓库存在未提交修改，停止，避免覆盖"
}

git status
git log -3 --oneline

robocopy $new $repo /MIR /XD ".git" "node_modules" "dist"
$robocopyCode = $LASTEXITCODE
if ($robocopyCode -ge 8) { throw "robocopy 复制失败，错误码：$robocopyCode" }

cd $repo
git status
npm ci
if ($LASTEXITCODE -ne 0) { throw "Git 仓库 npm ci 失败，停止部署" }
npm run verify
if ($LASTEXITCODE -ne 0) { throw "第二次 npm run verify 失败，停止部署" }

git add -A
git status
git commit -m "release: v0.5.0-alpha.5.1.9"
if ($LASTEXITCODE -ne 0) { throw "git commit 失败，停止" }

git push origin main
if ($LASTEXITCODE -ne 0) {
    throw "git push 失败；代码已安全提交在本地，不要重新复制或重新 commit"
}

Write-Host "alpha.5.1.9 已推送，等待 GitHub Actions 绿色成功"
```

## 专项验收

1. 主屏左侧不再出现竖白线；
2. 长按进入编辑态后 Widget / App / Dock 不整体下移；
3. 主屏至少有两页，可左右滑动；
4. 把 App 拖到第二页后，退出编辑 / 刷新仍留在第二页；
5. 「编辑页面」可新增页面，多于两页时可删除页面；
6. 音乐 App 使用单音符图标，与「一起听」Widget 一致；
7. Dock、音乐、海龟汤、角色、聊天、记忆等原数据正常。
