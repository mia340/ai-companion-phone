# V0.5.0-alpha.5.5.0 部署与更新

本版本新增原生 App「心跳飞行棋」。IndexedDB 仍为 V18、Backup 仍为 V12，不需要清空数据。

HomeLayout revision 升到 13。首次读取旧 revision 12 布局时，Runtime 会把 `couple-board` 补进第一个可用桌面槽位；不会重做旧版 Widget 尺寸迁移，也不会重置用户的壁纸、Dock、文件夹或现有 App 排列。

推荐只使用随 Release ZIP 一起提供的 ASCII-only PowerShell 5.1 部署脚本。脚本会：

```text
ZIP SHA-256 / source identity
→ npm ci
→ npm run verify
→ clean Git preflight
→ robocopy /MIR
→ npm ci
→ npm run verify
→ release:git-working
→ git add -A
→ release:staged-check
→ git diff --cached --check
→ forbidden path check
→ commit
→ push
```

验收重点：

- Launcher 可看到「心跳飞行棋」并能正常打开。
- 能选择一个角色、聊天/面对面模式、L1–L4 强度。
- L4 未确认 18+ 时不能开局；角色年龄明确小于 18 时不能启用成人模式。
- 棋盘可掷骰子、移动、触发挑战、换题、跳过、完成和结算。
- “带到知间聊天”只生成草稿，不自动发送。
- 刷新/退出后仍可继续未结束的一局。

测试定义为 66 files / 563 declarations；最终以部署机两轮 `npm run verify` 实际输出为准。
