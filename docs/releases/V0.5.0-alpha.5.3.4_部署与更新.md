# V0.5.0-alpha.5.3.4 部署与更新

本版本是 **时光 V1.3 · 事件智能整理**。

## 新增

- 事件详情支持 AI 摘要候选；必须返回当前 event id 与完整 evidence ids，任何漏证据/伪造 evidence 都会被 Runtime 拒绝。
- AI 摘要只有用户确认后才保存；evidence 集合变化后旧摘要自动失效。
- 事件可写用户备注，备注不会自动进入角色 Prompt。
- 带聊天来源的 evidence 可查看原消息前后各一条上下文。
- 事件详情支持 evidence 上移/下移，人工顺序会持久化；自动事件首次排序会安全转换为人工事件。
- 主动旧事可以使用仍然有效的用户确认摘要，event id + evidence ids guard 保持不变。

## 数据

IndexedDB V18 / Backup V12 / HomeLayout revision 12 均不变，无需清数据。新增元数据继续放在 `appCustomizations.sharedTimelineState` 非索引字段。

## 验收

两次 `npm run verify` 均应看到：

```text
Test Files  59 passed (59)
Tests       500 passed (500)
```

随后 `vue-tsc -b && vite build` 与 Release Safety 必须全部成功。
