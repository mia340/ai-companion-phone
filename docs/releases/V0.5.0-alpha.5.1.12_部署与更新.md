# V0.5.0-alpha.5.1.12 部署与更新

本版继续使用 **IndexedDB V18 / Backup V12**，不要清除浏览器站点数据、IndexedDB 或 LocalStorage。
> **R3 修正版**：R2 已修复 Backup Zod transport/domain 的 24 个类型边界问题，但 Windows `vue-tsc` 又准确暴露出测试夹具里最后一个错误：`MessageStatus` 使用了不存在的 `sent`。R3 已改为当前真实状态值 `delivered`。请勿再使用 R1/R2，本次只使用 `windows-safe-r3.zip`。


固定门禁：**解压 → `npm ci` → `npm run verify` → 检查 Git 工作树 → robocopy → 再次 `npm ci && npm run verify` → commit → push**。任一 verify 失败立即停止。

## 本版专项验收

部署后至少检查：

1. App 与 Widget 可在同一 4×6 Grid 内移动，App↔App 可交换，Widget 可改尺寸与跨页；
2. 最近的人 / 世界状态默认 2×1，音乐默认 4×1；旧大尺寸布局会自动收窄；
3. 音乐 Widget 不再显示右侧独立播放箭头；
4. 编辑态不再出现右上角大块“完成”区域，桌面背景点击可退出编辑；
5. 照片 / 日历 Widget、主题预设、HomeLayout 单独导入导出可用；
6. Character Card 导入页可看到结构化兼容 / 安全报告；
7. Prompt Debug 可查看 Context Inspector 与 WorldBook Activation Inspector 的逐条判定；
8. 备份导入在破坏性清库前执行 Zod envelope 与跨表引用完整性 preflight；损坏备份应被拒绝而不改动当前数据。
