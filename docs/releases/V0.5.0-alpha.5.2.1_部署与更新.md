# V0.5.0-alpha.5.2.1 部署与更新

本版本是 **ChatRoom Generation Runtime 拆分第二阶段（扩大范围版）**。一次性下沉“最终回复整理 + 持久化决策 + Action 落库编排”，不升级 IndexedDB、Backup Schema 或 Launcher Schema，不需要清站点数据。

## 本轮重点

- 最终 AI 输出的 Regex 显示投影、宏替换、presence override、消息 shaping、最终 visible output 和 persistence mode 改由 Runtime 统一计算。
- recall / reaction / typing pause / voice / emoji / image placeholder / 普通 text 的持久化编排从 View 下沉到 Runtime。
- 流式最终消息复用时补齐 `regexApplied` 元数据，和非流式落库保持一致。
- Provider 失败仍真实上抛，不使用本地角色内容续写。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  46 passed (46)
Tests       394 passed (394)
```

随后 `vue-tsc -b && vite build` 与 `release:source-check` 必须成功。
