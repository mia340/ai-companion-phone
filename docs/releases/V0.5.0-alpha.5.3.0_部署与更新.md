# V0.5.0-alpha.5.3.0 部署与更新

本版本新增 **「时光 / 共同回忆」V1**。不升级 IndexedDB、Backup 或 Launcher HomeLayout revision，不需要清站点数据。

## 新功能验收

- 桌面编辑器能看到「时光」App；新安装默认桌面包含它，已有自定义桌面不会被强制重排。
- 记忆中心顶部可进入「时光」。
- 时光页只显示有真实来源的记忆 / 动态 / 关键状态历史；可按角色筛选、收藏、隐藏、改标题。
- “查看来源”能跳回原朋友圈动态或原聊天消息。
- “AI 从证据中整理候选”只返回现有 evidence id；候选不会自动修改记忆，必须用户确认后才保存标题/收藏偏好。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  54 passed (54)
Tests       453 passed (453)
```

随后 `vue-tsc -b && vite build` 与 Release Safety 必须全部成功。
