# V0.5.0-alpha.5.1.18 Release Manifest

- Version: `0.5.0-alpha.5.1.18`
- Focus: Launcher Page Compositor V2 / persistent visual blank-page fix
- IndexedDB: V18（无迁移）
- Backup: V12
- Deployment gate: Windows `npm run verify` must pass twice before push.

## Main changes

- 移除 `.hm-pages-track` 的长轨道分页渲染。
- 每个桌面页改为绝对定位的独立 compositor layer，按 `pageIndex - currentPage` 计算 translate。
- 移除 `.hm-pages` / `.hm-page` 的 `contain: layout paint`，避免 Chromium 在 transformed flex page 上出现已存在 DOM 但不绘制内容的情况。
- 手势分页和编辑态边缘翻页继续沿用现有 Launcher Runtime。
