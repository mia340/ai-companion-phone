## 本版核心

1. 固定 50/50 游戏页：上半地图、下半互动，不再拖拽/展开/收起。
2. 当前题禁止替换；骰子落到哪题，就围绕哪题继续。
3. 跳过题目必须得到对方同意。
4. 用户题的跳过请求由角色基于人设/Memory 决定 approve/decline。
5. 角色题只有角色主动 requestSkip 时才由用户批准。
6. 停止现实身体互动或结束整局始终不需要对方批准。
7. Memory、Shared Timeline、OOC Audit、18+ 门禁与单题单归属规则继续保留。
