# V0.5.0-alpha.5.1.27 部署与更新

本版本是 **WorldBook Engine 测试补强版**，不修改 IndexedDB、Backup Schema、Launcher Schema，也不改变现有世界书运行时规则。

## 本轮验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  43 passed (43)
Tests       366 passed (366)
```

随后 `vue-tsc -b && vite build` 必须成功，`release:source-check` 必须全绿。

## 新增回归保护

新增 `src/services/lorebookService.test.ts`，直接覆盖：关键词 / regex / selective、scanDepth、上下文匹配、递归、sticky/cooldown/delay、group、probability、token budget、At-Depth / Outlet。

## 数据安全

本版本无数据库迁移。升级时不要清站点数据、IndexedDB 或 LocalStorage；旧角色、聊天、记忆、朋友圈、世界书、Persona、资源绑定和桌面布局应全部保留。
