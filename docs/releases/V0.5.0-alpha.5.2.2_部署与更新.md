# V0.5.0-alpha.5.2.2 部署与更新

本版本是 **Generation Runtime 第三阶段（Community UI Repair + State/Memory Side Effects）**。继续缩小 `ChatRoom.vue` 的职责，但不升级 IndexedDB、Backup Schema 或 Launcher Schema，不需要清站点数据。

## 本轮重点

- Community UI 合同校验、历史作者状态延续、本地 repair、紧凑状态补全、一次 AI 内容纠偏和失败降级统一下沉到 `communityUiRepairRuntime.ts`。
- 最终 repair 后会重新解析 canonical assistant 文本，避免 `rawContent` 已修复、status/actions 却仍来自旧文本。
- Conversation State / Lorebook timed state / state history / 主观观察记忆 / Character mood/activity side effects 下沉到 `assistantStateEffectsRuntime.ts`。
- 候选回复明确不写会话状态、记忆或角色 mood/activity。
- Provider 失败仍真实上抛；Community UI repair 失败只回退第一版真实 Provider 输出，不本地续写角色内容。

## 验收重点

两次 `npm run verify` 均应看到：

```text
Test Files  49 passed (49)
Tests       416 passed (416)
```

随后 `vue-tsc -b && vite build` 与 `release:source-check` 必须成功。
