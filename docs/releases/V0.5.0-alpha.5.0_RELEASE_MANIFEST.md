# V0.5.0-alpha.5.0 Release Manifest

## 主题

Social Runtime V1：持久后台朋友圈、多角色评论串、可继续回复。

## 主要变更

- 新增 App 级 `Social Runtime`，朋友圈 AI 互动不再依赖 `MomentsView.vue` 页面内定时器。
- 用户发动态后，多角色按“回复热度”错峰排队评论；离开朋友圈页后任务仍保留。
- 用户回复某位角色评论后，被回复角色会通过持久队列继续接话。
- 角色可以回复其他角色评论，形成“角色 ↔ 角色 ↔ 用户”的多人评论串。
- 角色自主动态和手动生成的角色动态也可触发其他角色自然串门。
- 新增线程深度上限、幂等键、失败重试、异常 running 恢复，避免无限互聊与重复执行。
- 新增角色对角色动态评论 / 评论线程 Prompt；信息不足时禁止凭空假设亲密关系。
- `momentSocialSettings.ts` 抽离朋友圈回复热度与候选选择，为 Social Runtime 与后续群聊复用。
- 删除朋友圈页旧的 reactionTimers 页面生命周期逻辑。

## 数据版本

- IndexedDB：V17（新增 `socialActivities` 运行时队列）
- Backup：V11（不变；队列属于可重建运行时元数据，恢复备份时会清空）
- V16 → V17 为增量加表，不清理原有角色、聊天、Persona、朋友圈动态或评论。

## 验证状态

- 修改 TS + `MomentsView.vue` script 已通过 TypeScript 5.8.3 `transpileModule` 语法检查。
- 静态测试定义：32 test files / 289 tests。
- 当前容器无法完成依赖安装，因此完整 `npm run verify` 仍以 Windows/CI 为最终发布门禁。
