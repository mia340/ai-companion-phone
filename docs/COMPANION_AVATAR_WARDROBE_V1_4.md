# Companion Avatar / 穿搭 V1.4

版本：`0.5.0-alpha.5.9.4`

V1.4 修正 V1.3 的核心视觉偏差：V1.3 虽扩展了服装、配饰、颜色和 64×80 程序化 Sprite，但大预览仍然是几何 SVG，和已确认的暖系像素概念图差距过大。

本版把已确认的原创概念美术真正接入穿搭 Runtime：

- 默认精品套装的大预览改为原创像素插画 Look Artwork，而不是把 64×80 棋盘 Sprite 放大到主舞台。
- 套装列表同步使用对应插画缩略图，选择套装时所见即所得地展示风格方向。
- 男女各保留多种方向：甜美花园 / 复古学院 / 黑色酷甜 / 清爽休闲 / 城市约会 / 户外阳光 / 居家等。
- 小游戏继续使用轻量 `CompanionPixelAvatar` 作为运行时移动 Sprite；穿搭数据仍由同一 `AvatarAppearanceProfile` 驱动。
- 用户已有 V1/V1.1/V1.2/V1.3 数据不迁移、不删除；IndexedDB、Backup、HomeLayout revision 均不升级。

说明：精品插画预览是风格化套装展示，当前自由调色、逐件搭配仍由实时程序化 Sprite 反映。后续若要让棋盘小人达到同等级美术，需要继续把这些概念方案拆成真正透明 Sprite Sheet，而不能再依赖几何 SVG 放大。
