# Companion Avatar / Wardrobe V1.1

版本：`0.5.0-alpha.5.9.1`

## 目标

V1.1 聚焦实际可用性和角色观感。上一版把角色预览放在长页面顶部，用户向下选择发型、衣服时会失去实时预览；CSS 小人也过于块状，容易出现“头发盖脸、像背影”的问题。

## 固定预览工作台

穿搭页现在锁定为上下两层工作台：上方始终保留角色和房间预览，下方只滚动当前编辑分类。人物不会因为编辑项很多而离开视线。

编辑分类拆成：人物、头发、上装、下装、配饰、套装。切换分类不会改变人物预览位置。

## 像素角色 V1.1

公共 `CompanionPixelAvatar` 改用 64×82 SVG 像素骨架，保持正面脸部始终可见，并增加：

- 更明确的头、脸、身体、手臂、腿和鞋比例；
- 发型前后分层，长发不再整块盖住脸；
- 眼睛、腮红、嘴部与简单阴影；
- 裙装 / 裤装 / 上装的可读差异；
- 眼镜、耳饰、项链、帽子、发带；
- idle / walk / rollDice / hug / kiss 等共享动画接口继续保留。

视觉方向参考的是“温暖农场 RPG / 16-bit 角色编辑器”的可读性和像素层次，不复制任何现成游戏素材。

## 数据和复用

WardrobeState 仍为 V1；每个角色与“我”继续拥有独立 Appearance Profile，多套 Outfit 与男女版型保持兼容。心跳飞行棋无需数据迁移即可继续读取当前造型。
