## 当前已知限制

- 当前 AI 回复仍是本地规则模拟
- 尚未接入真实大语言模型
- 角色详情和编辑页尚未完成
- 尚未提供正式角色删除
- 尚未处理删除角色后的关联会话和消息
- 没有数据导出、导入与备份
- 不同浏览器环境的数据相互隔离
- 尚未实现四层记忆
- 尚未实现关系数值和情绪演化
- 尚未实现群聊
- 尚未实现朋友圈
- 尚未实现主动消息
- 日记、音乐、钱包和游戏仍为占位页面
- Base64 图片长期大量使用可能增加 IndexedDB 体积
- 大量消息场景尚未加入分页或虚拟列表

## 开发测试约定

固定使用外部 Edge 浏览器：

`http://localhost:5173/`

不要混用 VS Code 内置浏览器判断角色是否丢失，因为不同浏览器环境拥有独立的 IndexedDB 与 localStorage。

每次修改后优先运行：

```powershell
npm run build
```

构建成功后再运行：

```powershell
npm run dev
```
