## 开发测试约定

固定使用外部 Edge 浏览器：

`http://localhost:5173/`

不要混用 VS Code 内置浏览器判断角色是否丢失，因为不同浏览器环境拥有独立的 IndexedDB 与 localStorage。

每次修改后优先运行：

```powershell
npm run build
```

构建成功后再运行：

```powershell
npm run dev
```

## V0.2.0 聊天核心完成情况

- 聊天主界面保持真实手机风格，不暴露模型技术信息
- 顶部头像进入角色心理状态，右上角进入音乐和聊天设置
- 心理活动为可公开的角色化生成内容，不是模型内部推理
- 支持网络或本地音频共同播放，并让角色生成陪听反应
- 支持最近消息、摘要和重要记忆三层上下文
- 支持记忆强度、自动提取、手动新增和删除
- 支持回复长度、多气泡、输入状态、自然延迟和停止生成
- 支持长按消息复制、删除和重新生成
- API 与模型状态仅在高级设置中查看
- 数据库版本为 V4，备份格式为 V2并兼容 V1
