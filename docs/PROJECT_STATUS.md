# AI Companion Phone 项目状态

## 当前版本

V0.3.2

## 当前阶段

项目已经形成单角色沉浸式陪伴聊天闭环，并完成第一版多模态图片理解与消息可靠性升级。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router（Hash 模式）
- Pinia
- Dexie / IndexedDB
- PWA
- Mock、DeepSeek 与 OpenAI 兼容 Provider

## 已完成

### Phone OS 与基础页面

- 锁屏、桌面、状态栏、Dock、Home Indicator
- 手机外框与移动端全屏布局
- 安全区和软键盘 Visual Viewport 适配
- 全项目隐藏浏览器滚动条并保留惯性滚动

### 用户与角色

- 用户资料、照片头像与简介
- 角色创建、编辑、详情和删除
- 人设、身份、说话方式、背景、喜好、心情和活动
- 通讯录分组与单聊自动创建

### 聊天体验

- 双方头像、左右气泡、时间分隔和滚动位置恢复
- 输入框自动增高、草稿保存、正在输入与自然发送间隔
- 停止等待回复、消息发送状态和失败重试
- 长按消息复制、回复、删除、重新生成和重新发送
- 引用回复、图片全屏预览和图片保存
- 图片选择预览、图片附言与确认发送
- 回到最新消息按钮和底部面板下滑关闭

### 多模态图片理解

- OpenAI 兼容 `image_url` 多模态消息
- 只向模型发送本次需要理解的图片，历史图片使用文字摘要避免重复传输
- 自动检测当前供应商、地址与模型的图片输入能力
- 图片能力结果缓存，切换接口或模型后自动失效
- 自动、强制启用、关闭三种模式
- 不支持图片时自动重试文字请求并使用自然兜底
- 图片最长边 1280 像素和目标体积压缩
- 首次发送图片的隐私确认

### 陪伴能力

- 角色心理活动和公开可见状态
- 三层聊天记忆：最近消息、旧对话摘要、重要记忆
- 图片附言参与记忆提取
- 关系成长：初识、熟悉、亲近、依赖、特别关系
- 图片分享参与亲密度、熟悉度和动态情绪
- 久未聊天时的主动陪伴消息
- 一起听歌和角色陪听反应

### Provider 与设置

- 本地模拟回复
- DeepSeek
- OpenAI 兼容接口
- 模型列表拉取、连接测试和错误中文说明
- 图片理解测试、能力状态和自动降级
- 技术信息仅放在聊天设置“高级”区域与模型设置页

### 数据

当前 IndexedDB 表仍为 V5 架构：

- worlds
- characters
- contactGroups
- conversations
- messages
- userProfiles
- modelSettings
- chatSettings
- memories
- conversationStates
- musicStates
- relationships
- relationshipEvents

新增消息字段不需要新增索引，因此无需升级 Dexie 表结构。备份格式升级为 V4，可选择是否包含图片，并兼容导入 V1、V2、V3。

## 当前限制

- 是否能识图最终取决于具体模型和接口是否接受 OpenAI 兼容多模态格式
- 当前只支持一次发送一张图片
- 图片仍以 Data URL 保存在消息记录中，大量图片会占用 IndexedDB
- 图片理解结果尚未单独保存为结构化描述，长期记忆主要来自用户附言
- 数据只保存在当前浏览器，不会自动跨设备同步
- 长消息列表尚未使用分页或虚拟列表
- 群聊、朋友圈、日记、钱包和游戏仍未完成

## 下一里程碑
