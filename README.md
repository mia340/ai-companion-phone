# 虚拟手机 · AI 陪伴世界

V0.2.0 可交互原型：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Dexie + PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## V0.2.0 已完成

- 干净的真实手机式聊天页，不在主界面展示模型名称或接口状态
- 点击聊天顶部头像查看角色化心情、状态与可公开的心理活动
- 右上角“♫”一起听歌：网络音频、本地音频、播放进度与角色陪听反应
- 右上角“•••”聊天设置：回复长度、多气泡、输入动画、自然间隔
- 三层聊天记忆：最近消息、旧对话摘要、重要记忆
- 自动提取用户姓名、喜好、事件、关系与约定，也可手动管理记忆
- 长按消息复制、删除或重新生成角色回复
- 停止生成、草稿保存、滚动位置恢复、时间分隔与沉浸式错误提示
- 技术信息仅放在聊天设置的“高级”区域
- Dexie 数据库升级到 V4，备份格式升级到 V2并兼容旧备份
- Mock、DeepSeek 与 OpenAI 兼容 Provider 继续可用

## 设计说明

“心理活动”是根据角色设定和聊天内容生成的、面向用户展示的虚构角色表现，不是模型内部推理或思维链。
