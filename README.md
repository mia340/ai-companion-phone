# 虚拟手机 · AI 陪伴世界

V0.3.2 可交互原型：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Dexie + PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## V0.3.2 已完成

- 支持图片与附言作为同一条消息发送
- 选择图片后先预览，可删除、更换或补充文字再确认发送
- 支持 OpenAI 兼容多模态 `image_url` 请求，视觉模型可以根据图片内容回复
- 图片理解支持自动检测、手动启用、手动关闭和不支持时自动降级
- 模型设置页新增“测试图片理解”与能力状态
- 不支持视觉时不会猜测图片细节，也不会在聊天中解释技术限制
- 图片最长边压缩到 1280 像素，并继续压缩到适合本地保存的体积
- 消息新增发送中、发送失败、停止等待和重新发送
- 图片消息长按可回复、保存、删除或重新发送
- 发送图片时显示“正在认真看你发来的图片”状态
- 图片附言继续参与记忆提取，图片分享会影响关系成长与角色情绪
- 备份格式升级至 V4，可选择是否包含聊天图片，并显示图片数量和体积
- 保留 V0.3.1 的引用回复、图片预览、软键盘适配、隐藏滚动条与底部面板手势

## 图片理解使用条件

图片回复与当前模型能力有关，同时要求接口兼容 OpenAI 多模态消息格式。建议进入：

```text
设置 → API 与模型 → 图片理解
```

先保存接口配置，再点击“测试图片理解”。自动模式下，首次发送图片也会自动检测；如果接口不支持，应用会改用不猜测图片内容的自然回应。

## 隐私与数据

- 第一次选择图片时会提示：图片需要发送给当前配置的模型服务进行理解。
- 请避免上传身份证、银行卡、私密文件等敏感内容。
- 图片和聊天数据保存在当前浏览器的 IndexedDB 中，不同浏览器和设备不会自动同步。
- 导出备份时可以关闭“包含聊天图片”，减小 JSON 文件体积。
