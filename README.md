# 虚拟手机 · AI 陪伴世界

V0.3.3 可交互原型：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Dexie + PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## V0.3.3 已完成

### 流式陪伴回复

- 支持 OpenAI 兼容 SSE 流式回复，角色文字会在气泡中逐步出现
- 图片理解请求同样支持流式输出
- 本地模拟模式可离线测试逐步回复效果
- 不返回 SSE 的兼容接口会自动按普通 JSON 回复处理
- 聊天设置新增“边想边回复”，可随时关闭流式显示
- 等待首段内容时保留角色化“正在输入”状态

### 停止与异常恢复

- 点击“停止”后保留已经生成的部分，不再整段丢失
- 流式中断时保留现有内容，并显示“回复中断”状态
- 页面刷新或意外退出后，遗留的发送中消息会恢复为可重试状态
- 流式写入采用节流持久化，减少 IndexedDB 高频写入
- 回复期间仅在用户仍位于最新消息附近时自动跟随滚动

### 聊天结构优化

- 消息气泡拆分为 `ChatMessageItem.vue`
- 输入区、图片预览条和引用预览拆分为 `ChatComposer.vue`
- `ChatRoom.vue` 继续负责会话编排、关系、记忆、音乐和请求生命周期
- 组件拆分后，后续增加多图、语音和消息样式更容易维护

### 继续保留

- 单图真实理解、图片附言、图片压缩与隐私提示
- 视觉能力自动检测与不支持时自然降级
- 引用回复、失败重试、重新生成、图片保存和全屏预览
- 长期记忆、关系成长、主动消息、心理活动与一起听歌
- V4 数据备份，可选择是否包含聊天图片

## 流式回复说明

默认会开启：

```text
聊天页 → 右上角 ••• → 聊天 → 边想边回复
```

接口支持标准 OpenAI SSE 时会实时显示；接口忽略 `stream: true` 但返回普通 JSON 时，应用仍能正常显示完整回复。若某个兼容接口的流式实现异常，可在聊天设置中关闭“边想边回复”。

## 图片理解使用条件

图片回复取决于具体模型是否支持视觉输入，同时要求接口兼容 OpenAI 多模态 `image_url` 消息格式。可进入：

```text
设置 → API 与模型 → 图片理解
```

保存接口配置后点击“测试图片理解”。

## 隐私与数据

- 图片理解会把图片发送给当前配置的模型服务
- 请避免上传身份证、银行卡和私密文件等敏感内容
- 聊天数据保存在当前浏览器的 IndexedDB 中，不会自动跨设备同步
- 导出备份时可以关闭“包含聊天图片”，减小文件体积
