# 虚拟手机 · AI 陪伴世界

V0.3.1 可交互原型：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Dexie + PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## V0.3.1 已完成

- 沉浸式角色聊天，主聊天界面不展示模型名称或接口状态
- 角色心理活动、关系成长、动态情绪与主动陪伴
- 一起听歌、三层聊天记忆、草稿保存和停止等待回复
- 输入框自动增高、手机软键盘与安全区适配
- 全局隐藏浏览器滚动条，同时保留触摸惯性滚动
- 消息气泡动画、回到最新消息按钮
- 长按消息复制、回复、删除或重新生成角色回复
- 图片消息、自动压缩和全屏预览
- 底部面板支持下滑关闭
- 页面切换加入轻量手机式动画
- Mock、DeepSeek 与 OpenAI 兼容 Provider
- 备份格式 V3，包含关系成长与关系事件，兼容 V1、V2 导入

## 重要说明

- 技术信息只显示在聊天设置的“高级”区域。
- 图片和聊天数据保存在当前浏览器的 IndexedDB 中，不同浏览器和设备之间不会自动同步。
- 大量图片会占用浏览器存储空间，建议定期使用“数据备份”导出 JSON 文件。
